# HDPS 公开实现核对

核对依据：作者仓库 `74587887/HDPS`，提交 `1105b54c2c29f7702a34cba677a1b93e74187a4a`。实时查询确认此提交仍为仓库最新提交。本地 54 个非缓存文件的 Git blob SHA 均与该提交一致，清单见 source_verification.json；原始 Code 目录未改动。

## 已确认的实现差异

| 项目 | 作者公开实现 | 上一轮自行重写的 paper_equations_v1 |
|---|---|---|
| 解码器 | TAESD3 AutoencoderTiny | 完整 SD3 AutoencoderKL |
| 解码器与潜变量精度 | VAE/初始潜变量 FP16；损失使用 float 输出 | VAE/潜变量 FP32；transformer 仍 FP16 |
| 潜空间对齐 | L2 norm × sigma，固定步长；高斯任务步长 15 | 平方 L2 sum，初始步长 .01，每次梯度更新再作 Armijo 回溯 |
| 对齐预算 | 每外循环 15 次梯度更新，每次只解码一次 | 15 次梯度更新，另为每次回溯候选重复解码 |
| 高斯任务像素循环 | Nx=20，lr_x=1e-4 | 同样 Nx=20，但后验目标和梯度尺度改写 |
| 像素目标 | MSE mean / (1e-5)^2；锚点项 / sigma²；最后裁剪 [-1,1] | likelihood / .03²；tau²=sigma²/(1+sigma²)；循环输出不裁剪 |
| CFG | uncond + 2 × (cond-uncond) | 3 × cond - 2 × uncond |
| 高斯任务初始化 | E(Aᵀy) | E(A†y)，调用截断 SVD 伪逆 |
| 时间格 | shift=4；设 100 步后取后 50 步，与 ratio=.8 混合初始化 | .8 到 0 的均匀 50 步 |
| 输出图像 | save_image(normalize=True)，按单张极值拉伸 | 固定 [-1,1] 映射到 [0,1] 后裁剪 |
| 退化对象 | solve.py 在图像循环外构造一次；随机 mask/motion kernel 在同一任务内复用 | 每幅图重新构造，按图生成种子 |
| FlowDPS | 16 次数据一致性更新 | 改为论文 B.2 的 3 次 |
| FLAIR | 最多 15 次 DC，达到测量误差阈值会提前停止 | 移除提前停止，强制 15 次 |

来源：[基础模型与 Tiny VAE](https://github.com/74587887/HDPS/blob/1105b54c2c29f7702a34cba677a1b93e74187a4a/sd3_sampler.py#L39-L68)、[HDPS 更新](https://github.com/74587887/HDPS/blob/1105b54c2c29f7702a34cba677a1b93e74187a4a/sd3_sampler.py#L813-L981)、[官方运行脚本](https://github.com/74587887/HDPS/blob/1105b54c2c29f7702a34cba677a1b93e74187a4a/scripts/run_sampling-hdps.sh)、[数据处理与保存](https://github.com/74587887/HDPS/blob/1105b54c2c29f7702a34cba677a1b93e74187a4a/solve.py)、[评估口径](https://github.com/74587887/HDPS/blob/1105b54c2c29f7702a34cba677a1b93e74187a4a/eval.py)。

这些改动同时影响计算量和重建结果。将该重写版本直接当作论文复现实验的处理不妥；应该先建立作者公开代码基线，再把论文与代码的差异作为独立对照。

## 已有慢版本实测

GPU2（RTX4090），FFHQ 00000，高斯去模糊，768²，50 外循环。完整采样耗时 **1125.7988 秒**，约 18.76 分钟。该单样本 PSNR=15.7199、SSIM=.06323，结果用于定位实现差异。

作者高斯任务每图解码调用为 50 × (1+15) + 1 = **801 次**。慢版本每次对齐还评估回溯候选；其保存的接受步长证明每图增加 **4200～6030 次候选解码**，总计 **5001～6831 次解码**。这些是由每外循环的最小/最大接受步长推得的界限。

运行成本由两项叠加：解码次数增加约 6.2～8.5 倍，同时每次调用从 Tiny FP16 换成了完整 VAE FP32。模型装载、指标计算均不包含在上述 sampling_seconds 中；断点与状态记录包含在内。

## 作者代码小规模测速

benchmark_public.py 直接生成作者 sampler 的路径适配副本，断言 HDPS 的 data_consistency_x、data_consistency_z、get_pinv、calculate_v 的 AST 与原始代码完全一致。仅添加观察钩子、模型绝对路径、Tiny VAE 零 shift、冻结预训练权重，以及移除未使用的 PIQ 对象构造；没有修改采样更新、步数、步长、CFG 或调度。

测量同一 FFHQ 00000、同一 768² 预处理、同一高斯前向与观测种子 513319557、同一 GPU2。运行两次完整 50 步作者算法，并测量 Tiny/完整 VAE 在 FP16/FP32 下的解码及反向耗时。实际结果写入 benchmark_results.json，启动装载时间与单图采样时间分开记录。

论文 Table 3 的 15.46 秒对应 Nx=15、Nz=15；公开高斯任务使用 Nx=20、Nz=15。两者预算略有区别，测速用于判断量级与定位额外开销，完整指标对齐还需统一论文与代码未详列的设置。

## 已完成的实际结果

| 运行 | 完整单图采样时间 | 解码调用数 | 单图 PSNR |
|---|---:|---:|---:|
| 作者公开算法，第 1 次 | 19.6341 s | 801 | 30.0996 dB |
| 作者公开算法，第 2 次 | 19.0729 s | 801 | 30.0996 dB |
| 自行改写的慢版本 | 1125.7988 s | 5001～6831 | 15.7199 dB |

两次作者算法输出 PNG 的 SHA256 完全一致：`82c7460d5d5f19c5bfb68d997a5afc891108acb2ab87f4c5ad18e36c41b7dde1`。慢版本相对第二次作者算法慢 59.03 倍。PSNR 是同一幅图的诊断值；两种算法的初始化、目标、CFG、调度与保存映射均有差别，不能把质量差异归因于某一项改动。

| 解码器与精度 | 单次前向中位数 | 单次前向+输入反向中位数 |
|---|---:|---:|
| author_Tiny_FP16 | 7.678 ms | 14.146 ms |
| Tiny_FP32 | 9.670 ms | 18.784 ms |
| full_SD3_VAE_FP32 | 144.442 ms | 321.347 ms |
| full_SD3_VAE_FP16 | 82.011 ms | 186.136 ms |

每个微基准预热 1 次、计时 5 次，使用相同 768² 张量尺寸。完整 VAE FP32 的前向约为 Tiny FP16 的 18.81 倍，前向+输入反向约为 22.72 倍。总体开销还包含共同的 flow 模型、像素梯度和记录工作，因此不直接将这些比值相乘。
