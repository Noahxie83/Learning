# First Time
## Abstract：
问题：如何让神经网络从不断的“加深“中获益
动机：需要改善深层神经网络可训练性
**方法：**残差学习框架**：以其输入为参照学习残差函数，而不是直接学习没有显式参照的函数
结果：这些残差网络组成的**集成模型**在 ImageNet 测试集上取得了 <u>3.57% </u>的错误率
意义：残差网络可以达到层数更多，但是计算复杂度反而更低的效果

## Conclusion：
*无*

# Second Time
## 1. Introduction
问题：即使信号和梯度能正常传播，深层网络仍可能训练不好
动机：网络加深后，训练错误率也升高
<mark style="background:#fff88f"><font color="#ff0000">核心方法</font></mark>：假设某几层实现的变换为 $H(x)$。普通结构让这些层直接学习 $H(x)$。作者通过快捷连接：$H(x)=F(x)+x$ **卷积层学习 $F(x)$，输入 $x$ 则通过另一条路径直接传递**。

## 2. Related Work
两条线 <font color="#ff0000">残差表示</font>和<font color="#ff0000">快捷连接</font>

| 已有基础                       | 本文进一步做的事情         |
| -------------------------- | ----------------- |
| 残差表达有时更有效                  | 将残差定义为相对于模块输入的修正  |
| 快捷连接可以帮助信息传播与训练            | 用恒等快捷连接实现残差**相加** |
| 已有带门控的深层网络（HighwayNetwork） | 采用简单的无门控恒等路径      |

## 3. Deep Recidual Learning
搭建残差神经网络的两种方案
- 下采样，增加的通道零填充
- 使用 $1\times 1$ 投影卷积

训练设置
1. 随机调整图片尺度
2. 随机裁出 $224\times 224$ 区域
3. 使用水平翻转和颜色增强
4. 减去像素均值
