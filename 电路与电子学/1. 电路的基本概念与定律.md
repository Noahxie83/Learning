## 1.1 电路
定义：由一些电气元件按一定的要求构成的<font color="#ff0000">电流通路</font>
组成：
	电源：把其它形式的能量转换成电能的能量转换装置
	负载：把电能转换成其它形式的能量的能量转换装置
		不能绝对化电源和负载，例如手机电池
	中间环节：连接电源与负载之间并具有传输、控制电能作用的部分，如电线、开关等
分类：
	力能电路：如电力系统；目标：提高效率，节能降耗；特征：电压高，电流大，功率大
	信号电路：目标：减小失真；特征：电压低，电流小，功率小
		电路失真是指==信号在电路中传输或放大时发生变形，导致输出信号与输入信号不完全一致的现象==
电路模型：把实际电路中的器件用理想化的元件符号代替，从而构建出能够反映其主要电气特性的数学模型
- **开路**：支路电流为零，端口电压不一定为零；
- **短路**：理想连接两端电压为零，电流不一定为零；
- **实际器件与理想模型**：模型保留主要特征，并不表示现实器件完全符合。

## 1.2 电路的基本概念
**1.2.1 电流**：
	平均电流：$I=\frac{Q}{T}$ 
	瞬时电流： $i=\frac {dq}{dt}$
	方向：
		实际方向：具有局限性
		参考方向（正方向）：参考方向与实际方向一致时为正值，反之为负值
**1.2.2 电压**：
	描述电场力做功
	电压    $u_{ab}=\int^{b}_{a}\frac{Fdl}{q}=\int^{b}_{a}Edl=V_{a}-V_{b}$   
	电动势 $\epsilon_{ab}=\int^{b}_{a}\frac{F_{0}dl}{q}$
	电压方向为电势降的方向，电动势的方向为电势升的方向
	关联参考方向：电压的参考方向与电流参考方向一致，反之为非关联参考方向
**1.2.3 功率**：
	$P=\frac{dW}{dt}=\frac{dW}{dq}·\frac{dq}{dt}=ui$
- 电流参考方向**流入电压正端**，即关联参考方向时：$\boxed{p_{吸收}=ui}$
- 电流参考方向**流入电压负端**时：$\boxed{p_{吸收}=-ui}$
- $p_吸收 > 0:吸收电能；p_吸收 < 0:向外释放电能$
## 1.3 基尔霍夫定律
支路：两个结点之间的一段电路，支路中各元件通常流过同一个电流。
结点：两条或两条以上支路相连接的地方。
回路：从某个结点出发，沿着支路走一圈，最后又回到原结点的闭合路径。
网孔：电路中不能再分割、内部不包含其他支路的最小回路。
**1.3.1 KCL**
	==**在集总电路中，任意时刻，流经任一结点的各支路电流代数和为零。**==
	即$\boxed{\sum_k i_k=0}$
	$\sum i_{流入}=\sum i_{流出}$
		规定电流流入结点为正，流出为负
	原因：<u>电荷守恒原理</u>
	两套符号：
		1.电流的参考方向跟结点的相互关系
		2.电路的参考方向跟实际方向的相互关系
	推广应用：
		**广义结点**：用一个假想的封闭面把一部分电路包起来，把这个封闭面看成一个“大结点”
		KCL对广义结点也适用
		三极管电流关系：
			$i_c\approx\beta i_b$ ：是三极管**正向放大区、忽略漏电等影响时的近似关系**，不是 KCL，也不适用于所有工作状态。
			$i_e=i_b+i_c$ ：在所选参考方向下，由 **KCL** 得到
**1.3.2 KVL**
	**==在集总电路中，在任意时刻沿着电路中任意回路一周的电压代数和为零==**
	即$\boxed{\sum u=0}$
	规定电压与回路绕行方向一致为正，反之为负
	原因：能量守恒定律
	两套符号：
		1. 电压参考方向与回路绕行方向的相互关系
		2. 电路的参考方向与实际电势降的相互关系
	推广应用：
		**开口网络**：有未连接的端点
		**KVL对开口网络也适用：网络中有开路，不代表 KVL 失效；但不能把一条未闭合路径上的电压代数和直接写成零。**
		$\boxed{u_{ab}=V_a-V_b}$
## 1.4 电路元件
**1.4.1 无源电路元件**
	<font color="#ff0000">电阻元件</font>**R**（耗能元件）
	![[Pasted image 20260921110550.png|188]]![[Pasted image 20260921110658.png|199]]
		线性电阻：$i=\frac {u}{R}$
			串联：总电阻等于各电阻之和
			并联：总电阻倒数等于各电阻倒数之和
			[***星形—三角变换***](https://lms.xjtu.edu.cn/course/34529/learning-activity#/1370021)
		非线性电阻（PN结、二极管等）：
			静态电阻：$R_D=\frac {u}{i}$
			动态电阻：$r_D=\frac{du}{di}$
		**线性电阻的伏安特性是过原点的直线，非线性电阻的伏安特性是曲线；
		非线性电阻的电阻值会随工作状态改变。**
	<font color="#ff0000">电感元件</font>**L**
	![[Pasted image 20260921110516.png|172]]
		$L=\frac{\Psi}{i}=\frac{N\phi}{i}$
		$u=-e=-(-\frac{d\Psi}{dt})=L\frac{di}{dt}$
		$p=ui=L\frac{di}{dt}i$
		$W_L=\int^t_{t_0} pdt=\frac12Li^2$
	<font color="#ff0000">电容元件</font>**C**
	![[Pasted image 20260921110019.png|217]]
		$C=\frac qu$
		$i=\frac {dq}{dt}=C\frac{du}{dt}$
		$W_C=\frac 12 Cu^2$
		
| 性质         | 理想线性电感              | 理想线性电容              |
| ---------- | ------------------- | ------------------- |
| 关联参考方向下的关系 | $u_L=L\,di_L/dt$    | $i_C=C\,du_C/dt$    |
| 储能         | $W_L=\frac12Li_L^2$ | $W_C=\frac12Cu_C^2$ |
| 直流稳态等效     | 短路                  | 开路                  |
| 连续性        | 无冲激电压时，电流不能突变       | 无冲激电流时，电压不能突变       |
	***对偶特性***
		**即数学方程和网络结构可以互相替换**
		电压对电流，电阻对电导；  
		电感对电容，串联对并联；
		KVL 对 KCL，电压源对电流源；  
		开路对短路，网孔对节点。
		*注：*
			电导 $G$
			$G=\frac 1R,R=\frac 1G,u=Ri,i=Gu$
**1.4.2 有源电路元件**
	**独立电源**
		**电压源**
			**理想电压源**
			![[Pasted image 20260921105127.png|418]]
				1. <mark style="background:#fff88f">恒压特性</mark>：电压源的输出电压仅是时间的函数$u_s(t)$，与负载无关
					$u_s=u$
				2. 电流随负载大小改变，即由外电路决定
					$i=\frac U{R_L}=\frac {u_s}{R_L}$
				3. 由于$P=ui$，所以理想电压源可以向外电路提供“无穷大功率”，即“无穷大电源”
			**实际电压源**
				一个<font color="#ff0000">理想电压源串联一个内阻</font>
				$\boxed{u=u_s-R_0i}$
			![[Pasted image 20260928104402.png|480]]
		**电流源**
			**理想电流源**
			![[Pasted image 20260921105553.png|512]]
				1.<mark style="background:#fff88f">恒流特性</mark>：电流源的输出电流仅是时间的函数$i_s(t)$，与负载无关
					$i_s=i$
				2.$u=iR_L=I_sR_L$
				3.由于$P=ui$，所以理想电流源可以向外电路提供“无穷大功率”，即“无穷大电源”；
			**实际电流源**	
				一个<font color="#ff0000">理想电流源并联一个内阻</font>
				$i=I_s-\frac u{r_0}\to \boxed{u=I_sr_0-r_0i}$
			![[Pasted image 20260928104506.png|513]]
		***等效电路***
			以上两种实际电源都是<font color="#ff0000">外特性相同</font>的等效电路
			$u_s=I_sr_0$
			$R_0=r_0$
		***理想电源模型***
			**理想电源模型不设置实际器件的电流、电压或功率上限；
			但这不意味着实际电源能提供无限功率。**
	**受控源**
		![[Pasted image 20260921115824.png|267]]
		受控源有四种形式:
		![[Pasted image 20260921110921.png|284]]
			a.电压控制电压源VCVS
			b.电压控制电流源VCCS
			c.电流控制电压源CCVS
			d.电流控制电流源CCCS
			
| 类型   | 控制关系            | 参数单位        |
| ---- | --------------- | ----------- |
| VCVS | $u_o=\mu u_c$   | $\mu$：无量纲   |
| VCCS | $i_o=g u_c$     | $g$：S       |
| CCVS | $u_o=r i_c$     | $r$：Ω       |
| CCCS | $i_o=\beta i_c$ | $\beta$：无量纲 |
		**处理办法：**
		1. <u>按电压源或电流源的形式列写电路方程，同时联立控制关系；不能把受控源的数值当成独立给定量。</u>
		2. **使用叠加定理时，只将其他独立电源置零，受控源不能随意关掉。**
		3. <u>列电路的补充方程，把控制量用待求量表示</u>
