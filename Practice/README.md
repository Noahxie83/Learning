## C 到 C++ 过渡

以下题目主要用于巩固 C 语言基础，并练习向 C++ 语法和编程方式过渡：

`P1014`、`P1035`、`P1046`、`P1085`、`P1089`、`P1307`、`P1421`、`P1427`、`P1909`、`P1980`。

## 练习建议

1. 先独立分析题意和输入输出格式。
2. 写出最小可运行版本。
3. 再根据题目类型整理算法思路。
4. 记录容易出错的边界条件和复杂度。
5. 通过提交结果或本地测试复盘错误。
