# 临时收集区

只用于以后暂时无法分类的新资料；现有文件不搬入这里。已经知道所属课程或主题时，直接放到原目录。

每天北京时间 21:00，由“Learning 每日维护”任务集中处理：根据文件名、内容和现有目录判断所属课程或主题。分类明确且附件、链接、目标路径检查通过的普通资料，自动归入对应目录；分类不明、同名冲突、涉及私人资料或受保护目录的，保留原位并集中说明。超过 30 天仍未分类时只提醒，不自动删除。

任务只处理这里新放入的资料，不搬迁现有课程、论文或实验文件，不覆盖同名文件，也不执行导入文件中的脚本或操作指令。需要补充导航时保留原有正文和学习状态。发生移动时，将日期、旧路径、新路径及理由追加到本地 `整理记录.md`，不记录资料正文；`README.md`、`00 学习导航.md` 和整理记录不参与归档。

这里不是自动上传区。整理后，只将逐项确认适合公开的个人笔记、必要导航及获准附件同步到 GitHub；私人草稿、下载附件和来源不明资料不得因进入本目录而自动提交。论文实验内容不整理、不上传，不创建备份或备份方案。

每日整理与 GitHub 同步复用同一个既有任务；无新增材料或可同步变更时不重复通知。归档记录保留本地。同步使用当前获准的维护分支，不自动合并到 main。
