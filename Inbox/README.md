# 临时收集区

只用于以后暂时无法分类的新资料；现有文件不搬入这里。已经知道所属课程或主题时，直接放到原目录。

每周浏览一次：决定所属主题、来源、是否适合公开，以及是否值得保留。超过 30 天仍未分类时只提醒，不自动删除或移动。

这里不是自动上传区。私人草稿、下载附件和来源不明资料不得因进入本目录而自动提交。论文实验内容继续保持原位置，不在本轮整理范围。
