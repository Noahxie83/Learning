# 本地只读维护工具

此工具仅使用 Python 3 标准库，保留在本地。它不运行课程脚本、Notebook 或模型文件，不创建报告文件，不移动或改写笔记，不修改学习状态、Git 索引或远程引用。

## 使用

在知识库根目录的 PowerShell 中运行：

```powershell
python -B -X utf8 .\tools\audit_vault.py
python -B -X utf8 .\tools\audit_vault.py --json
```

可选参数：

- `--root 路径`：检查另一个明确指定的目录；拒绝进入受保护的 Paper 目录及其子目录，也拒绝根路径或其上层含有目录链接的入口。
- `--hash-duplicates`：仅对同后缀、同大小且不超过 2 MiB 的 Markdown/PDF 计算哈希；默认不计算。
- `--check-remote`：额外用 `ls-remote` 读取各仓库 origin 的默认分支 HEAD，不执行 fetch。默认离线，ahead/behind 仅比较缓存引用。远程默认分支的查询结果不等于当前维护分支已经同步。
- `--strict`：读取错误、确定的目标缺失、大小写差异或越出知识库路径时返回非零状态。导航、歧义链接和字段候选仍需要人工判断。

所有结果输出到终端；没有自动写入模式，也没有上传、修复、删除或备份功能。

## 检查边界

- 内容扫描排除整个 `Paper/`，包括论文笔记和实验目录；不修改这些文件。指向该区域的链接标记为范围外，不据此断言其有效或失效。
- 跳过环境、依赖、缓存、下载数据、权重、结果目录、个人配置和 Junction。仅统计已进入扫描范围的文件，不能当作完整磁盘占用。
- 检查链接目标前先排除受保护路径、忽略目录和目录链接，不通过链接跟随到这些区域。
- Markdown 大于 2 MiB 时不解析正文。检查本地文件目标，不验证小节锚点、块标识或外部网页是否可访问。
- 支持常见 Markdown 相对链接、引用定义、Wiki 链接与附件、HTML 附件引用；跳过代码围栏、行内代码、缩进代码和注释。复杂 Markdown 语法仍可能需要人工复核。
- 同名 Wiki 目标无法唯一定位时报告歧义；已有目录链接也计入导航覆盖，不把每篇无直接入链笔记都视为孤立。
- 新 `Concepts/` 笔记检查 `title` 与 `note_type`，兼容 `type`；不要求历史课程页和 README 补齐 Frontmatter。
- Git 状态单独列出扫描范围内的有效嵌套仓库。主仓库的未跟踪数量可能包含 Paper，但不读取其正文、不暂存它们。被排除区域中的嵌套仓库不作同步结论。
- 进度只摘录 README 中的明确文字供人工核对，不推断掌握程度或自动判断冲突。

配置位于脚本顶部 `DEFAULT_CONFIG`，没有外部依赖或隐藏自动任务。解除 `Paper/` 排除范围须等待用户另行授权。
