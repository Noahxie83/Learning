## Obsidian 与 Git 使用

可以将克隆后的仓库根目录整体作为 Obsidian 仓库打开，通过本页进入学习材料。也可以打开 AI、CS 对应目录作为分库；Git 操作统一在 Learning 根目录进行。README 使用 GitHub 和 Obsidian 均支持的 Markdown 相对链接与图片语法。

首次使用时，在自己选择的父目录克隆仓库：

```powershell
git clone https://github.com/Noahxie83/Learning.git
Set-Location ./Learning
```

两台电脑交替使用时，先进入各自的仓库根目录，保存并检查修改；工作区干净后拉取，再开始学习：

```powershell
git status
git pull --ff-only origin main
```

结束学习后确认变更中没有敏感信息、意外删除或编译产物，再分步提交与推送：

```powershell
git add -A
git diff --cached --stat
git commit -m "更新学习资料"
git push origin main
```

任一步出错先停止处理，不强制推送。没有变化时无需创建空提交。个人自动同步配置不随仓库分发。
