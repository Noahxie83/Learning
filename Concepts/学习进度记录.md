# 学习进度记录规则

原有完成记录继续以[学习档案](../README.md)和对应课程页面为依据。本页只定义以后需要细分状态时的记录方式，不迁移、不覆盖已有状态。

## 独立维度

| 字段 | 可选值 | 依据示例 |
| --- | --- | --- |
| 当前安排 | 未开始、学习中、暂缓、待确认 | 本人当前安排 |
| 阅读或观看 | 未开始、部分、已完成、待确认 | 阅读或观看记录 |
| 课程完成 | 不适用、部分、已完成、待确认 | 原课程完成记录 |
| 核心概念 | 待确认、需要复习、本人确认理解 | 本人解释、推导或确认 |
| 代码练习 | 未做、部分、已完成、待确认 | 对应练习与记录 |
| 实现方式 | 待确认、教材跟做、第三方改编、独立实现 | 源码来源与个人工作说明 |
| 验证程度 | 未检查、运行通过、结果核对、按明确标准复现 | 命令、环境、输入、结果和比较标准 |
| 复习需求 | 待确认、需要、暂不需要 | 本人判断和具体问题 |

状态可以并存。例如课程完成后仍可需要复习；代码运行通过后仍可能没有独立实现。缺少依据写“待确认”，不推断为“未完成”。

## 按需使用的记录模板

只填写需要表达变化的维度，不要求给所有历史笔记补齐字段。以下是空模板，不代表真实学习状态：

```yaml
progress:
  reading:
    value: 待确认
    evidence: []
  implementation:
    value: 待确认
    evidence: []
  validation:
    value: 待确认
    evidence: []
  review:
    value: 待确认
    evidence: []
```

`evidence` 填原记录、笔记小节、习题、源码或运行记录的链接；本人确认注明日期。只有相关状态变化时才更新，导航页只链接依据，避免维护第二套完整进度表。

资料日期、整理日期和学习完成日期分别说明。维护工具只能提示疑点，不能根据日期、勾选数量或文件数量自动改写状态。
