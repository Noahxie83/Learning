> [!abstract] 本题概览
> 模拟无优先级、严格从左到右求值的整数四则运算器，遇 `=` 结束，遇到除数为 `0` 或非法运算符输出 `ERROR`。核心模式是**先读首操作数、再按“运算符 + 操作数”成对流式消费输入**。

---

## 题目描述

模拟简单运算器的工作。假设计算器只能进行加减乘除运算，运算数和结果都是整数，4 种运算符的优先级相同，按从左到右的顺序计算。

### 输入格式

输入在一行中给出一个四则运算算式，没有空格，且至少有一个操作数。遇等号 `=` 说明输入结束。

### 输出格式

在一行中输出算式的运算结果，或者如果除法分母为 0 或有非法运算符，则输出错误信息 `ERROR`。

### 输入样例

```text
1+2*10-10/2=
```

### 样例预期输出

```text
10
```

---

## 解题思路与核心知识点

1. **流式状态机解析**：
   - 算式结构始终满足：`num_0 (op_1 num_1) (op_2 num_2) ... =`；
   - 因此先在循环外读入首个数初始化累加器 `res = num`；
   - 进入循环后每次先读运算符 `scanf(" %c", &symbol)`，若为 `=` 立刻输出结果并退出（天然兼容仅有单个数字如 `5=` 的边界输入）；否则再读入下一个操作数 `num` 并更新 `res`。
2. **异常提前终止**：
   - 遇到 `/` 且 `num == 0` 时，先拦截并输出 `ERROR\n` 后 `return 0;` 退出，避免除零崩溃；
   - 遇到非 `+ - * / =` 的字符进入 `else` 分支，同样输出 `ERROR\n` 并直接退出。

> [!tip] 边界微调观察
> 源码在判断非法运算符前先执行了 `scanf("%d", &num);`。若非法符号后面紧跟的不是数字（例如 `1$=`），`scanf("%d", &num)` 会匹配失败但不会阻塞，代码随后仍会进入 `else` 分支输出 `ERROR`。更严谨的写法是把非法运算符检查放在读取下一个 `num` 之前（或直接用 `switch (symbol)` 分派）。

## 完整源码

```c
/*
模拟简单运算器的工作。假设计算器只能进行加减乘除运算，运算数和结果都是整数，4种运算符的优先级相同，按从左到右的顺序计算。
输入格式：
输入在一行中给出一个四则运算算式，没有空格，且至少有一个操作数。遇等号”=”说明输入结束。
输出格式：
在一行中输出算式的运算结果，或者如果除法分母为0或有非法运算符，则输出错误信息“ERROR”。
输入样例：   1+2*10-10/2=
*/
#include <stdio.h>
int main(){
char symbol ='0';
int num=0;
scanf("%d",&num);
int res=num;
while(symbol!='='){
    scanf(" %c",&symbol);
    if (symbol=='='){
        printf("%d",res);
        break;
    }
    scanf("%d",&num);
    if (symbol=='+'){
        res+=num;
    }
    else if (symbol=='-'){
        res-=num;
    }
    else if (symbol=='*'){
        res*=num;
    }
    else if (symbol=='/'){
        if (num==0){
            printf("ERROR\n");
            return 0;
        }
        else {
            res/=num;
        }
    }
    else {
        printf("ERROR\n");
        return 0;
    }
}
	return 0;
}
```
