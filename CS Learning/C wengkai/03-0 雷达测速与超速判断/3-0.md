> [!abstract] 本题概览
> 模拟雷达测速仪：输入汽车速度 $V$，判断是否严格大于 60 mph，并按固定格式输出 `Speeding` 或 `OK`。本题练习最基础的 `if / else` 二分支结构与边界条件判断。

---

## 题目描述

模拟交通警察的雷达测速仪。输入汽车速度，如果速度超出 60 mph，则显示 `Speeding`，否则显示 `OK`。

### 输入格式

输入在一行中给出 1 个不超过 500 的非负整数，即雷达测到的车速。

### 输出格式

在一行中输出测速仪显示结果，格式为 `Speed: V - S`，其中 `V` 是车速，`S` 或者是 `Speeding`、或者是 `OK`。

### 输入样例 1

```text
40
```

### 输出样例 1

```text
Speed: 40 - OK
```

### 输入样例 2

```text
75
```

### 输出样例 2

```text
Speed: 75 - Speeding
```

---

## 解题思路与核心知识点

1. **严格不等号边界**：题目要求“超出 60 mph”才判定超速，因此边界 `v == 60` 属于 `OK`，判断条件应为 `v > 60` 而非 `v >= 60`。
2. **分支输出**：用 `if (v > 60)` 与 `else` 分别输出对应字符串即可；也可以用三目运算符简化为一行：`printf("Speed: %d - %s", v, v > 60 ? "Speeding" : "OK");`。

> [!tip] 题面符号细节
> 原始题面注释中的输出样例 2 含有一个排版连字符 `–`（En Dash），而输出格式定义与样例 1 均为标准 ASCII 半角减号 `-`。实际评测应以半角 `-` 为准（源码中的写法完全正确）。

## 完整源码

```c
/*
模拟交通警察的雷达测速仪。输入汽车速度，如果速度超出60 mph，则显示“Speeding”，否则显示“OK”。
输入格式：
输入在一行中给出1个不超过500的非负整数，即雷达测到的车速。
输出格式：
在一行中输出测速仪显示结果，格式为：“Speed: V - S”，其中V是车速，S或者是Speeding、或者是OK。
输入样例1：
40
输出样例1：
Speed: 40 - OK
输入样例2：
75
输出样例2：
Speed: 75 – Speeding
*/
#include <stdio.h>

int main (){
    int v;
    scanf("%d",&v);
    if(v>60){
        printf("Speed: %d - Speeding",v);
    }
    else{
        printf("Speed: %d - OK",v);
    }
    return 0;
}
```
