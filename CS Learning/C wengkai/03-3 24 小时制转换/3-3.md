> [!abstract] 本题概览
> 将形如 `21:11` 的 24 小时制时间转换为 `9:11 PM` 的 12 小时制表示。重点考察 `scanf` 格式串匹配分隔符 `:`，以及**中午 12 点（`12:x PM`）与午夜 0 点（`0:x AM`）**这两个易错边界。

---

## 题目描述

编写一个程序，要求用户输入 24 小时制的时间，然后显示 12 小时制的时间。

### 输入格式

输入在一行中给出带有中间的 `:` 符号（半角冒号）的 24 小时制的时间，如 `12:34` 表示 12 点 34 分。当小时或分钟数小于 10 时，均没有前导的零，如 `5:6` 表示 5 点零 6 分。

提示：在 `scanf` 的格式字符串中加入 `:`，让 `scanf` 来处理这个冒号。

### 输出格式

在一行中输出这个时间对应的 12 小时制的时间，数字部分格式与输入的相同，然后跟上空格，再跟上表示上午的字符串 `AM` 或表示下午的字符串 `PM`。如 `5:6 PM` 表示下午 5 点零 6 分。

注意：在英文的习惯中，中午 12 点被认为是下午，所以 24 小时制的 `12:00` 就是 12 小时制的 `12:0 PM`；而 0 点被认为是第二天的时间，所以是 `0:0 AM`。

### 输入样例

```text
21:11
```

### 输出样例

```text
9:11 PM
```

---

## 解题思路与核心知识点

1. **格式串字面量匹配**：`scanf("%d:%d", &hour, &min)` 会自动消费输入流中的冒号 `:`，直接将两侧整数存入 `hour` 与 `min`。
2. **三段边界映射**：

| 24 小时制 `hour` | 12 小时制小时数 | 上/下午标记 | 示例 |
| :---: | :---: | :---: | --- |
| `0 <= hour <= 11` | `hour` | `AM` | `0:0` → `0:0 AM`，`5:6` → `5:6 AM` |
| `hour == 12` | `12`（==不可减 12==） | `PM` | `12:0` → `12:0 PM` |
| `13 <= hour <= 23` | `hour - 12` | `PM` | `21:11` → `9:11 PM` |

> [!tip] 嵌套判断结构清晰性
> 源码先以 `hour >= 12` 区分 `PM` 与 `AM`，在 `PM` 内部再区分 `hour > 12` 与 `hour == 12`，精确避开了把 `12:30` 错算成 `0:30 PM` 的常见坑点。

## 完整源码

```c
/*
编写一个程序，要求用户输入24小时制的时间，然后显示12小时制的时间。
输入格式：
输入在一行中给出带有中间的“:”符号（半角的冒号）的24小时制的时间，如12:34表示12点34分。当小时或分钟数小于10时，均没有前导的零，如5:6表示5点零6分。
提示：在scanf的格式字符串中加入“:”，让scanf来处理这个冒号。
输出格式：
在一行中输出这个时间对应的12小时制的时间，数字部分格式与输入的相同，然后跟上空格，
再跟上表示上午的字符串“AM”或表示下午的字符串“PM”。如“5:6 PM”表示下午5点零6分。
注意，在英文的习惯中，中午12点被认为是下午，所以24小时制的12:00就是12小时制的12:0 PM；
而0点被认为是第二天的时间，所以是0:0 AM。
输入样例：    21:11
输出样例：    9:11 PM
*/
#include <stdio.h>
int main(){
	int hour,min;
	scanf("%d:%d",&hour,&min);
	if(hour>=12){
		if(hour-12>0){
			printf("%d:%d PM",hour-12,min);
		}else{
			printf("%d:%d PM",hour,min);
		}
	}else{
		printf("%d:%d AM",hour,min);
	}
	return 0;
}
```
