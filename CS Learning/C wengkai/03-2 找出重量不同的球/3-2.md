> [!abstract] 本题概览
> 已知 A、B、C 三个球中有两个等重、仅一个不同，要求找出不一样的那个球。利用**两两相等排除法**，最多只需 2 次比较即可唯一确定答案。

---

## 题目描述

三个球 A、B、C，大小形状相同且其中有一个球与其他球重量不同。要求找出这个不一样的球。

### 输入格式

输入在一行中给出 3 个正整数，顺序对应球 A、B、C 的重量。

### 输出格式

在一行中输出唯一的那个不一样的球。

### 输入样例

```text
1 1 2
```

### 输出样例

```text
C
```

---

## 解题思路与核心知识点

由于题目保证恰好两球相等、一球不同，直接利用排除法构造 3 路 `if / else if / else` 决策树：

1. 若 `a == b`，则 A、B 为相同球，异球必为 **C**；
2. 否则（A 与 B 不同，其中必有一个异球），再测 `b == c`：若成立则 B、C 相同，异球必为 **A**；
3. 否则 A 与 C 必相同，异球只能是 **B**。

> [!tip] 逻辑完备性与最简比较次数
> 无需把 `a == c` 也单独写进第三个 `else if`——在题目约束成立的前提下，前两条都不满足时 `B` 是唯一剩余可能，最多仅需 **2 次比较**即可覆盖全部 3 种情况。

## 完整源码

```c
/*
三个球A、B、C，大小形状相同且其中有一个球与其他球重量不同。要求找出这个不一样的球。
输入格式：输入在一行中给出3个正整数，顺序对应球A、B、C的重量。
输出格式：在一行中输出唯一的那个不一样的球。
输入样例：1 1 2
输出样例：C
*/
#include <stdio.h>
int main(){
	int a,b,c;
	scanf("%d %d %d",&a,&b,&c);
	if(a==b){
		printf("C\n");
	}
    else if(b==c){
		printf("A\n");
	}
    else{
		printf("B\n");
	}
	return 0;
}
```
