# 3-2 — 找出重量不同的球

[查看源码](./3-2.c) · [返回 C wengkai 笔记目录](../README.md)

本文按原文件中的注释整理，保留原始学习记录；文末附完整源码。

## 题目与学习笔记

三个球A、B、C，大小形状相同且其中有一个球与其他球重量不同。要求找出这个不一样的球。

### 输入格式

输入在一行中给出3个正整数，顺序对应球A、B、C的重量。

### 输出格式

在一行中输出唯一的那个不一样的球。

### 输入样例

```text
1 1 2
```

### 输出样例

```text
C
```

## 完整源码

```c
/*
三个球A、B、C，大小形状相同且其中有一个球与其他球重量不同。要求找出这个不一样的球。
输入格式：输入在一行中给出3个正整数，顺序对应球A、B、C的重量。
输出格式：在一行中输出唯一的那个不一样的球。
输入样例：1 1 2
输出样例：C
*/
#include <stdio.h>
int main(){
	int a,b,c;
	scanf("%d %d %d",&a,&b,&c);
	if(a==b){
		printf("C\n");
	}
    else if(b==c){
		printf("A\n");
	}
    else{
		printf("B\n");
	}
	return 0;
}
```
