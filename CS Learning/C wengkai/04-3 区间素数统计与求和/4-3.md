> [!abstract] 本题概览
> 统计区间 $[M, N]$ 内素数的个数并求其总和。本题练习**外层区间遍历 + 内层试除法素数判定**以及标志变量（flag）模式；同时特别需要留意 `1` 不是素数这一经典边界坑。

---

## 题目描述

本题要求统计给定整数 $M$ 和 $N$ 区间内素数的个数并对它们求和。

### 输入格式

输入在一行中给出 2 个正整数 $M$ 和 $N$（$1 \le M \le N \le 500$）。

### 输出格式

在一行中顺序输出 $M$ 和 $N$ 区间内素数的个数以及它们的和，数字间以空格分隔。

### 输入样例

```text
10 31
```

### 输出样例

```text
7 143
```

---

## 解题思路与核心知识点

1. **试除法 + 标志位模式**：对区间内每个整数 `i`，先假设它是素数（`sign = 1`），依次尝试用 `j = 2, 3, ...` 整除 `i`；一旦发现 `i % j == 0` 就将 `sign` 置 `0`。内层循环结束后，若 `sign == 1` 则累加计数 `n` 与总和 `sum`。
2. **两个值得注意的边界与效率改进**：

> [!warning] 源码边界 Bug：`M = 1` 时会把 `1` 误判为素数
> 在数学定义中，**1 既不是素数也不是合数**。但在原始 `4-3.c` 中，当 `i = 1` 时，`while (j <= i / 2)` 即 `2 <= 0` 不执行，`sign` 保持初始值 `1`，导致 `1` 被错误计入素数个数与总和！
> - **边界修正**：循环开始时加一句 `if (i < 2) sign = 0;`（或将起点钳制为 `if (M < 2) M = 2;`）。
> - **效率优化**：① 试除上界只需到 $\sqrt{i}$（写作 `j * j <= i`，避免浮点 `sqrt`）；② 一旦 `i % j == 0` 应立即 `break;` 跳出内层循环，无需继续无效试除。

## 完整源码

```c
/*
本题要求统计给定整数M和N区间内素数的个数并对它们求和。
输入格式：   输入在一行中给出2个正整数M和N（1<=M<=N<=500）。
输出格式：   在一行中顺序输出M和N区间内素数的个数以及它们的和，数字间以空格分隔。
输入样例：   10 31
输出样例：    7 143
*/
#include <stdio.h>
int main(){
    int M,N,n=0,sum=0,i,j,sign=0;
    scanf("%d %d", &M, &N);
    i=M;
    while(i<=N){
        j=2;
        sign=1;
        while(j<=i/2){
            if(i%j==0){
                sign=0;
            }
            j++;
        }
        if(sign==1){
            n+=1;
            sum+=i;
        }
        i++;
    }
    printf("%d %d\n",n,sum);
return 0;
}
```
