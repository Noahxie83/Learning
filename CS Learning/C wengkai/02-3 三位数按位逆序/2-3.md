> [!abstract] 本题概览
> 读入一个正三位数，将其百位、十位、个位逆序重组并输出，且不带前导零。通过整除 `/` 与取余 `%` 拆解各位后**按数值重新构造整数**，即可天然消除前导零。

---

## 题目描述

程序每次读入一个正 3 位数，然后输出按位逆序的数字。

注意：当输入的数字含有结尾的 0 时，输出不应带有前导的 0。比如输入 `700`，输出应该是 `7`。

### 输入格式

每个测试是一个 3 位的正整数。

### 输出格式

输出按位逆序的数。

### 输入样例

```text
123
```

### 输出样例

```text
321
```

---

## 解题思路与核心知识点

1. **按位拆分公式**：设三位数为 $x$：
   - 个位：$d_0 = x \bmod 10$
   - 十位：$d_1 = (x / 10) \bmod 10$
   - 百位：$d_2 = x / 100$
2. **重构整数消前导零**：计算 `ret = d0 * 100 + d1 * 10 + d2` 后以 `%d` 输出。以 `700` 为例：$0 \times 100 + 0 \times 10 + 7 = 7$，直接输出 `7`，无需额外写 `if` 判断前导零。

> [!tip] 对比“逐位打印”方案
> 若直接 `printf("%d%d%d", d0, d1, d2)`，输入 `700` 会错误打印出 `007`。==将结果拼回一个整数再统一输出，是消除前导零最简洁的做法。==

## 完整源码

```c
/*
程序每次读入一个正3位数，然后输出按位逆序的数字。
注意：当输入的数字含有结尾的0时，输出不应带有前导的0。比如输入700，输出应该是7。
输入格式：   每个测试是一个3位的正整数。
输出格式：    输出按位逆序的数。
输入样例：   123
输出样例：   321
*/
#include <stdio.h>
int main(){
	int tmp=0;
	scanf("%d",&tmp);
	int ret=0;
	ret=tmp%10*100+tmp/10%10*10+tmp/100;
	printf("%d",ret);
	return 0;
}
```
