> 输入正整数 $N$（$1 \le N \le 9$），输出从 $1 \times 1$ 到 $N \times N$ 的下三角部分口诀表。核心知识点是**双层嵌套循环控制行列三角结构**，以及 `printf` 的宽度与左对齐说明符 `%-4d`。

---

## 题目描述

下面是一个完整的下三角九九口诀表：

```text
1*1=1
1*2=2   2*2=4
1*3=3   2*3=6   3*3=9
1*4=4   2*4=8   3*4=12  4*4=16
1*5=5   2*5=10  3*5=15  4*5=20  5*5=25
1*6=6   2*6=12  3*6=18  4*6=24  5*6=30  6*6=36
1*7=7   2*7=14  3*7=21  4*7=28  5*7=35  6*7=42  7*7=49
1*8=8   2*8=16  3*8=24  4*8=32  5*8=40  6*8=48  7*8=56  8*8=64
1*9=9   2*9=18  3*9=27  4*9=36  5*9=45  6*9=54  7*9=63  8*9=72  9*9=81
```

本题要求对任意给定的 1 位正整数 $N$，输出从 $1 \times 1$ 到 $N \times N$ 的部分口诀表。

### 输入格式

输入在一行中给出一个正整数 $N$（$1 \le N \le 9$）。

### 输出格式

输出下三角 $N \times N$ 部分口诀表，其中等号右边数字占 4 位、左对齐。

### 输入样例

```text
4
```

### 输出样例

```text
1*1=1   
1*2=2   2*2=4   
1*3=3   2*3=6   3*3=9   
1*4=4   2*4=8   3*4=12  4*4=16  
```

---

## 解题思路与核心知识点

1. **下三角双层循环**：
   - 外层循环控制行号 `i`（从 `1` 到 `N`）；
   - 内层循环控制列号 `j`（从 `1` 到 `i`），确保第 `i` 行恰好打印 `i` 个算式 `j*i=乘积`，每行结束后输出 `\n`。
2. **`printf` 宽度与对齐格式**：
   - `%4d`：最小宽度 4 列，默认**右对齐**（左侧补空格）；
   - `%-4d`：加上 `-` 标志改为**左对齐**（右侧补空格），恰好满足“等号右边数字占 4 位、左对齐”的排版要求，且天然让相邻算式对齐成列。

## 完整源码

```c
/*
下面是一个完整的下三角九九口诀表：
1*1=1
1*2=2   2*2=4
1*3=3   2*3=6   3*3=9
1*4=4   2*4=8   3*4=12  4*4=16
1*5=5   2*5=10  3*5=15  4*5=20  5*5=25
1*6=6   2*6=12  3*6=18  4*6=24  5*6=30  6*6=36
1*7=7   2*7=14  3*7=21  4*7=28  5*7=35  6*7=42  7*7=49
1*8=8   2*8=16  3*8=24  4*8=32  5*8=40  6*8=48  7*8=56  8*8=64
1*9=9   2*9=18  3*9=27  4*9=36  5*9=45  6*9=54  7*9=63  8*9=72  9*9=81
本题要求对任意给定的1位正整数N，输出从1*1到N*N的部分口诀表。
输入格式：   输入在一行中给出一个正整数N（1<=N<=9）。
输出格式：   输出下三角N*N部分口诀表，其中等号右边数字占4位、左对齐。
输入样例：   4
输出样例：
1*1=1
1*2=2   2*2=4
1*3=3   2*3=6   3*3=9
1*4=4   2*4=8   3*4=12  4*4=16
*/
#include <stdio.h>
int main(){
    int N,i=1,j;
    scanf("%d",&N);
    while(i<=N){
        j=1;
        while(j<=i){
            printf("%d*%d=%-4d",j,i,i*j);
            j++;
        }
        printf("\n");
        i++;
    }
    return 0;
}
```
