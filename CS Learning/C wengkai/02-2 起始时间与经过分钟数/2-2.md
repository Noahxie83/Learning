> [!abstract] 本题概览
> 输入四位数字表示的起始时间（如 `1120`）与可正可负的流逝分钟数，计算并输出终止时间。核心技巧是将“时、分”统一换算为**自 00:00 起的总分钟数**，一步化解进位、借位与跨多小时问题。

---

## 题目描述

有时候人们用四位数字表示一个时间，比如 `1106` 表示 11 点零 6 分。

现在，你的程序要根据起始时间和流逝的时间计算出终止时间。读入两个数字，第一个数字以这样的四位数字表示当前时间，第二个数字表示分钟数，计算当前时间经过那么多分钟后是几点，结果也表示为四位数字。

当小时为个位数时，没有前导的零，即 5 点 30 分表示为 `530`。注意，第二个数字表示的分钟数可能超过 60，也可能是负数。

### 输入格式

输入在一行中给出 2 个整数，分别是四位数字表示的起始时间、以及流逝的分钟数，其间以空格分隔。

注意：在起始时间中，当小时为个位数时，没有前导的零，即 5 点 30 分表示为 `530`；流逝的分钟数可能超过 60，也可能是负数。

### 输出格式

输出四位数字表示的终止时间。题目保证起始时间和终止时间在同一天内。

### 输入样例

```text
1120 110
```

### 输出样例

```text
1310
```

---

## 解题思路与核心知识点

1. **拆分时与分**：利用整除和取余分离小时与分钟：`hour = time / 100`，`min = time % 100`。
2. **统一基准单位（分钟）**：计算总分钟数 `ret = hour * 60 + min + pass`。无论 `pass` 是正数、超过 60，还是负数，只要结果在同一天内（$0 \le \text{ret} < 1440$），直接做加法即可自动完成进位与借位。
3. **还原时与分**：`hour = ret / 60`，`min = ret % 60`。

> [!warning] 源码细节排查：分钟小于 10 时的前导零
> 源码第 24 行写作 `printf("%d%d", hour, min);`。当终止时间的分钟数小于 10 时（例如 `11:05` 或 `0:05`），该写法会漏掉分钟十位的 `0`，错误输出为 `115` 或 `05`！
> - **修正方案**：改用 `printf("%d%02d", hour, min);`（当 `hour == 0` 时若要求不输出前导零如 `005` 需结合题意确认，多数 PAT 测试点接受 `%d%02d`，或直接 `printf("%d", hour * 100 + min)` 在 `hour > 0` 时同样正确）。

## 完整源码

```c
/*
有时候人们用四位数字表示一个时间，比如1106表示11点零6分。
现在，你的程序要根据起始时间和流逝的时间计算出终止时间。读入两个数字，第一个数字以这样的四位数字表示当前时间，
第二个数字表示分钟数，计算当前时间经过那么多分钟后是几点，结果也表示为四位数字。
当小时为个位数时，没有前导的零，即5点30分表示为530。注意，第二个数字表示的分钟数可能超过60，也可能是负数。
输入格式：
输入在一行中给出2个整数，分别是四位数字表示的起始时间、以及流逝的分钟数，其间以空格分隔。
注意：在起始时间中，当小时为个位数时，没有前导的零，即5点30分表示为530；流逝的分钟数可能超过60，也可能是负数。
输出格式：    输出四位数字表示的终止时间。题目保证起始时间和终止时间在同一天内。
输入样例：
1120 110
输出样例：
1310
*/
#include <stdio.h>
int main(){
    int time, pass;
    scanf("%d %d",&time,&pass);
    int hour=time/100;
    int min=time%100;
    int ret=hour*60+min+pass;
    hour=ret/60;
    min=ret%60;
    printf("%d%d",hour,min);
    return 0;
}
```
