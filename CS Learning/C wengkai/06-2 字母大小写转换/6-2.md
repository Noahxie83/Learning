> [!abstract] 本题概览
> 逐字符读取以 `#` 结尾的字符串，将小写字母转为大写、大写转为小写，其余字符保持不变。核心知识点是 **ASCII 编码区间（`'a'`–`'z'` 为 97–122，`'A'`–`'Z'` 为 65–90）及大小写固定偏移量 32**。

---

## 题目描述

输入一个以 `#` 结束的字符串，本题要求将小写字母全部转换成大写字母，把大写字母全部转换成小写字母，其它字符不变。

### 输入格式

输入在一行中给出一个长度不超过 40 的、以 `#` 结束的非空字符串。

### 输出格式

在一行中按照要求输出转换后的字符串。

### 输入样例

```text
Hello World! 123#
```

### 输出样例

```text
hELLO wORLD! 123
```

---

## 解题思路与核心知识点

1. **哨兵字符流**：无需提前开数组存储整行，直接用 `scanf("%c", &ch)`（或 `getchar()`）逐个读入字符，读到 `'#'` 时 `break`，其余字符实时转换并输出（空间复杂度 $O(1)$）。
2. **原始笔记中的 ASCII 编码映射**：

| 字符类别 | ASCII 范围 | 转换操作 |
| --- | :---: | --- |
| 小写字母 `a`–`z` | `97` – `122` | 减 `32` 转大写 |
| 大写字母 `A`–`Z` | `65` – `90` | 加 `32` 转小写 |
| 其他字符（空格、数字、标点） | 其余值 | 原样输出 |

> [!tip] 提升可读性：用字符常量或 `<ctype.h>` 替代魔数
> 在实际工程中，直接写 `ch >= 'a' && ch <= 'z'` 和 `ch -= 'a' - 'A'` 比硬编码 `97`、`122`、`32` 更直观且不易出错；更进一步，可直接引入标准库 `<ctype.h>`，使用 `islower` / `isupper` / `toupper` / `tolower` 完成判断与转换。

## 完整源码

```c
/*
输入一个以#结束的字符串，本题要求将小写字母全部转换成大写字母，把大写字母全部转换成小写字母，其它字符不变。
输入格式：    输入在一行中给出一个长度不超过40的、以#结束的非空字符串。
输出格式：    在一行中按照要求输出转换后的字符串。
输入样例：    Hello World! 123#
输出样例：    hELLO wORLD! 123
*/
#include <stdio.h>
/*ASCII:    a-->97  z-->122
            A-->65  Z-->90*/
int main(){
	char ch='0';
	int tmp=0;
	while(ch!='#'){
		scanf("%c",&ch);
		if(ch=='#')break;
		tmp=ch;
		if(tmp<=122&&tmp>=97){
			tmp-=32;
			ch= (char)tmp;
			printf("%c",ch);
		}else if(tmp>=65&&tmp<=90){
			tmp+=32;
			ch=(char)tmp;
			printf("%c",ch);
		}else {
			printf("%c",ch);
		}
	}
	return 0;
}
```
