## 题目描述

输入一个字符串，对该字符串进行逆序，输出逆序后的字符串。

### 输入格式

输入在一行中给出一个不超过 80 个字符长度的、以回车结束的非空字符串。

### 输出格式

在一行中输出逆序后的字符串。

### 输入样例

```text
Hello World!
```

### 输出样例

```text
!dlroW olleH
```

---

## 解题思路与核心知识点

### 1. 逆向指针输出 vs 原地双指针反转

| 方案 | 核心逻辑 | 时间复杂度 | 额外空间 | 适用场景 |
| --- | --- | :---: | :---: | --- |
| **逆向遍历输出（本源码）** | 从末尾字符向前逐个 `putchar(*p)` | $O(n)$ | $O(1)$ | 仅需输出，不要求修改原字符串 |
| **原地双指针交换** | `l = a`, `r = a + len - 1`，循环交换 `*l` 与 `*r` 直到 `l >= r` | $O(n)$ | $O(1)$ | 需要把反转结果保留在数组 `a` 中供后续使用 |

### 2. 边界陷阱检查

> [!warning] 注意起始指针 `a + strlen(a)` 会多输出一个 `'\0'`！
> 源码第 21 行写的是：
> ```c
> for (p = a + strlen(a); p >= a; p--) {
>     putchar(*p);
> }
> ```
> 对于长度为 $n$ 的字符串，有效字符位于 `a[0] .. a[n - 1]`，而 `a[n]`（即 `a + strlen(a)`）存放的是**空终止符 `'\0'`**！
> - 在终端直接观看时，NUL 字符（ASCII 0）通常不可见，肉眼容易忽略；
> - 但在严格逐字节比对的 OJ 判题器或管道重定向中，开头多出的 `'\0'` 可能导致 `Wrong Answer` 或 `Presentation Error`。
>
> **修正写法**：将初始位置改为最后一个有效字符 `p = a + strlen(a) - 1`（前提是非空串 `strlen(a) > 0`）。

## 完整源码

```c
/*
输入一个字符串，对该字符串进行逆序，输出逆序后的字符串。
输入格式：
输入在一行中给出一个不超过80个字符长度的、以回车结束的非空字符串。
输出格式：
在一行中输出逆序后的字符串。
输入样例：
Hello World!
输出样例：
!dlroW olleH
*/
#include <stdio.h>
#include <string.h>
int main(){
    char a[81],*p=a,s1;
    while ((s1=getchar())!='\n'){
        *p=s1;
        p++;
    }
    *p='\0';
    for (p=a+strlen(a);p>=a;p--){
        putchar(*p);
    }
    return 0;
}
```
