# C wengkai

翁恺老师 C 语言课程的学习代码与练习归档。

## 内容范围

本目录主要用于记录 C 语言从基础到进阶的学习过程，包含：

- 基本语法、变量、表达式和控制流。
- 函数、数组、指针和字符串。
- 结构体、链表等常见数据结构基础。
- 课程章节练习和独立示例。
- 大型程序结构相关的学习资料。

代码文件以课程练习为主，文件名通常按照课程章节或题目编号组织。

## 学习建议

建议按照章节顺序阅读代码，同时关注：

1. 函数参数和返回值的设计。
2. 指针、数组和内存之间的关系。
3. 头文件与源文件的组织方式。
4. 代码从单文件向多文件项目演进的过程。
