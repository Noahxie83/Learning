# C wengkai

翁恺老师 C 语言课程的学习代码与练习归档。

学习状态：已学完。

课程入口：[中国大学 MOOC](https://www.icourse163.org/learn/ZJU-9001?tid=9001#/learn/announce)。保留所选课程的学期链接，学习页可能需要登录。

## Markdown 笔记目录

本目录的 50 个 C 语言文件（含配套头文件）均配有 Markdown 笔记。47 个章节目录统一采用“章号-节号 解释性中文标题”命名（例如 `02-0 整数的和、差、积、商`）。章号补齐为两位，便于按名称排序；源码和 Markdown 文件名仍保留原章节编号，下方目录继续按章节顺序排列。`array`、`node` 配套头文件目录及多文件示例内的 `main`、`max` 子目录保留原名。

Markdown 将原注释整理为正文、用法表格、输入输出样例及带行号的注释索引，文末附完整源码。笔记保留学习时的记录，未进行逐项知识校订。

例如 `10-0.c`（句子中的单词逆序）现在位于：

```text
10-0 句子中的单词逆序/
├── 10-0.c
└── 10-0.md
```

### 配套源码说明

可变长数组和链表分别使用 ` array/array.h `、` node/node.h `。在各自源码文件夹编译时，使用 ` -I "../array" ` 或 ` -I "../node" ` 指定头文件目录；完整命令见对应笔记。

第 13 章的 `13-3 多文件程序结构` 目录需要同时编译 ` main/main.c ` 和 ` max/max.c `。

## 内容范围

本目录主要用于记录 C 语言从基础到进阶的学习过程，包含：

- 基本语法、变量、表达式和控制流。
- 函数、数组、指针和字符串。
- 结构体、链表等常见数据结构基础。
- 课程章节练习和独立示例。
- 大型程序结构相关的学习资料。

代码文件以课程练习为主，文件名通常按照课程章节或题目编号组织。

## 学习建议

建议按照章节顺序阅读代码，同时关注：

1. 函数参数和返回值的设计。
2. 指针、数组和内存之间的关系。
3. 头文件与源文件的组织方式。
4. 代码从单文件向多文件项目演进的过程。

根模块入口：[CS Learning/README.md](../README.md)。
