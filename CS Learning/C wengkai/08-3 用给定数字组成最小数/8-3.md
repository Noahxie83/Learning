> [!abstract] 本题概览
> 给定数字 `0`–`9` 各自的可用个数（总数 $\le 50$，至少包含 1 个非零数字），要求用尽所有数字拼出不含前导零的最小整数。核心思路为==贪心选最小非零位作首位 + 剩余数字升序流式输出（规避大整数溢出）==。

---

## 题目描述

给定数字 `0`–`9` 各若干个。你可以以任意顺序排列这些数字，但必须全部使用。目标是使得最后得到的数尽可能小（注意 `0` 不能做首位）。

例如：给定两个 `0`，两个 `1`，三个 `5`，一个 `8`，我们得到的最小的数就是 `10015558`。现给定数字，请编写程序输出能够组成的最小的数。

### 输入格式

每个输入包含 1 个测试用例。每个测试用例在一行中给出 10 个非负整数，顺序表示我们拥有数字 `0`、数字 `1`、……、数字 `9` 的个数。整数间用一个空格分隔。10 个数字的总个数不超过 50，且至少拥有 1 个非 `0` 的数字。

### 输出格式

在一行中输出能够组成的最小的数。

### 输入样例

```text
2 2 0 0 0 3 0 0 1 0
```

### 输出样例

```text
10015558
```

---

## 解题思路与核心知识点

### 1. 贪心构造策略

要让定长十进制数最小，高位应尽可能小；由于首位不能为 `0`，最优构造唯一且只需两步：

1. **确定首位**：从 `i = 1` 到 `9` 扫描计数数组 `a[]`，找到==第一个满足 `a[i] != 0` 的最小非零数字==，直接打印该数字，执行 `a[i]--` 并 `break`。
2. **输出其余各位**：从 `i = 0` 到 `9` 依次把剩余的 `a[i]` 个数字全部输出（此时所有的 `0` 紧跟在首位之后，使高位尽可能小）。

以输入样例 `a = [2, 2, 0, 0, 0, 3, 0, 0, 1, 0]` 为例：

- 第 1 步选出 `1` 输出，`a[1]` 从 `2` 减为 `1`；
- 第 2 步按 `0..9` 输出剩余数字：`00` + `1` + `555` + `8`；
- 最终流式拼接得到 `10015558`。

### 2. 复杂度与溢出规避

- **时间复杂度**：$O(D)$，其中 $D = \sum_{i=0}^{9} a_i \le 50$ 为数字总个数。
- **空间复杂度**：$O(1)$，仅用长度为 10 的频次数组。

> [!important] 为什么不能把结果存进 `int` 或 `long long`？
> 题目允许数字总数高达 **50 位**，而 64 位无符号整型 `unsigned long long` 最多仅能表示约 20 位十进制数（$1.84 \times 10^{19}$）。本题==直接按位流式 `printf("%d", i)` 输出==，无需构造整数变量，天然规避了大数溢出问题！

## 完整源码

```c
/*
给定数字0-9各若干个。你可以以任意顺序排列这些数字，但必须全部使用。目标是使得最后得到的数尽可能小（注意0不能做首位）。
例如：给定两个0，两个1，三个5，一个8，我们得到的最小的数就是10015558。
现给定数字，请编写程序输出能够组成的最小的数。
输入格式：
每个输入包含1个测试用例。每个测试用例在一行中给出10个非负整数，顺序表示我们拥有数字0、数字1、……数字9的个数。
整数间用一个空格分隔。10个数字的总个数不超过50，且至少拥有1个非0的数字。
输出格式：
在一行中输出能够组成的最小的数。
输入样例：
2 2 0 0 0 3 0 0 1 0
输出样例：
10015558
*/
#include <stdio.h>
int main(){
    int i,j;
    int a[10]={0};
    for (i=0;i<10;i++){
        scanf("%d",&a[i]);
    }
    for (i=1;i<10;i++){
        if(a[i]!=0){
            printf("%d",i);
            a[i]--;
            break;
        }
    }
    for (i=0;i<10;i++){
        for (j=0;j<a[i];j++){
            printf("%d",i);
        }
    }
    printf("\n");
    return 0;
}
```
