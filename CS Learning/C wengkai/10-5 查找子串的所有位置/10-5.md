> [!abstract] 本题概览
> 读入两行可能含空格的字符串（长度均 $< 10000$），找出第一个字符串在第二个字符串中**所有出现位置**（允许重叠匹配，0 起始下标）；若未出现则输出 `-1`。核心考点为==滑动窗口逐位比对、重叠匹配处理与截断复原技巧==。

---

## 题目描述

你会读到两个字符串，每个字符串占据一行，每个字符串的长度均小于 10000 字符，而且第一个字符串的长度小于第二个字符串的。你的程序要找出第一个字符串在第二个字符串中出现的位置，输出这些位置，如果找不到，则输出 `-1`。

- 注意：第一个字符的位置是 `0`；
- 注意：第一个字符串在第二个字符串中的位置可能不止一处（且允许位置重叠）；
- 注意：字符串中可能含有空格；
- 注意：两个字符串的长度一定大于 `0`。

### 输入格式

两个字符串，一行一个。

### 输出格式

第一个字符串在第二个字符串中出现的位置，按照从小到大的顺序排列，每个数字后面有一个空格。如果在第二个字符串中找不到第一个字符串，则输出 `-1`。

### 输入样例

```text
abba
ababbba abbabbabbabbaacc
```

### 输出样例

```text
8 11 14 17
```

---

## 解题思路与核心知识点

### 1. 滑动窗口匹配与重叠子串

设模式串 `a` 长度为 $m = \text{len}_1$，主串 `b` 长度为 $n = \text{len}_2$：

1. 窗口起始指针 `q` 从 `b` 逐字符滑到 `b + len2 - len1`（含右端点，共 $n - m + 1$ 个候选起点），同时用 `cnt` 记录当前 0 起始下标（也等价于 `q - b`）。
2. 在每个起点，暂存窗口右边界字符 `ch = *(q + len1)`，临时置为 `'\0'`，用 `strcmp(q, a) == 0` 判断当前窗口是否与 `a` 完全相等。
3. 比较完成后**立即恢复** `*(q + len1) = ch`，保证下一轮滑动窗口（仅右移 1 格！）不受污染。
4. 观察样例：`abbabbabbabba` 中 `abba` 的匹配位置为 `8, 11, 14, 17`——前一个 `abba` 末尾的 `a` 同时是下一个 `abba` 的开头！==每次仅步进 `q++`（而非跳过整个 `len1`）是捕获重叠匹配的关键==。

### 2. 算法复杂度与进阶对比

| 匹配算法 | 最坏时间复杂度 | 空间复杂度 | 特点 |
| --- | :---: | :---: | --- |
| 朴素滑动窗口（本源码） | $O((n - m + 1) \cdot m)$ | $O(n + m)$ | 实现直观；对一般文本接近线性，仅极端重复串退化 |
| `strncmp(q, a, len1)` | $O((n - m + 1) \cdot m)$ | $O(n + m)$ | ==无需临时修改并恢复主串 `b`==，更安全、支持 `const char*` |
| KMP 算法 | $O(n + m)$ | $O(m)$ | 预处理 `next` 前缀函数，消除主串回溯，最坏情况严格线性 |

> [!tip] 两个小细节
> 1. 源码中 `q = b;` 之后 `for (q = b; ...)` 已经重新初始化了 `q`，下标也可以直接写成 `(int)(q - b)`，省去维护单独变量 `cnt`。
> 2. 使用 `fgets()` 或带 `EOF` 判断的 `getchar()` 循环读行时，注意处理末尾可能存在的 `\r\n`（Windows 换行）与无换行 EOF 情况。

## 完整源码

```c
/*
题目说起来很简单,你会读到两个字符串,每个字符串占据一行,每个字符串的长度均小于10000字符,而且第一个字符串的长度小于第二个字符串的。
你的程序要找出第一个字符串在第二个字符串中出现的位置,输出这些位置,如果找不到,则输出-1。
注意,第一个字符的位置是0。
注意,第一个字符串在第二个字符串中的位置可能不止一处。
注意,字符串中可能含有空格。
注意,两个字符串的长度一定大于0。
输入格式:
两个字符串,一行一个。
输出格式:
第一个字符串在第二个字符串中出现的位置,按照从小到到的顺序排列,每个数字后面有一个空格。
如果在第二个字符串中找不到第一个字符串,则输出-1。
输入样例:
abba
ababbba abbabbabbabbaacc
输出样例:
8 11 14 17
*/
#include <stdio.h>
#include <string.h>
int main(){
    char a[10001],b[10001],*p=a,*q=b,s1,s2;
    while ((s1=getchar())!='\n'){
        *p=s1;
        p++;
    }
    *p='\0';
    while ((s2=getchar())!='\n'){
        *q=s2;
        q++;
    }
    *q='\0';
    q=b;
    int len1=strlen(a),cnt=0,len2=strlen(b),flag=0;
    for(q=b;q<=b+len2-len1;q++){
        char ch=*(q+len1);
        *(q+len1)='\0';
        if (strcmp(q,a)==0){
            printf("%d ",cnt);
            flag=1;
        }
        *(q+len1)=ch;
        cnt++;
    }
    if (flag==0){
        printf("-1");
    }
    return 0;
}
```
