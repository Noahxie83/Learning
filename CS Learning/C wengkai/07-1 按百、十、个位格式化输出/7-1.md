> [!abstract] 本题概览
> 用字母 `B` 表示“百”、`S` 表示“十”、`12...n` 表示个位数字，格式化输出不超过 3 位的正整数。源码复用了上一题的 `weishu()` 函数配合 `switch` 按位权输出，同时也可以对比更紧凑的固定三位算术拆解法。

---

## 题目描述

让我们用字母 `B` 来表示“百”、字母 `S` 表示“十”，用 `12...n` 来表示个位数字 $n$（$< 10$），换个格式来输出任一个不超过 3 位的正整数。

例如 `234` 应该被输出为 `BBSSS1234`，因为它有 2 个“百”、3 个“十”、以及个位的 `4`。

### 输入格式

每个测试输入包含 1 个测试用例，给出正整数 $n$（$< 1000$）。

### 输出格式

每个测试用例的输出占一行，用规定的格式输出 $n$。

### 输入样例 1

```text
234
```

### 输出样例 1

```text
BBSSS1234
```

### 输入样例 2

```text
23
```

### 输出样例 2

```text
SS123
```

---

## 解题思路与核心知识点

1. **位权驱动实现（源码思路）**：
   - 先用 `weishu(n)` 求出最高位权 `tmp`（对于 3 位数为 `100`，2 位数为 `10`，1 位数为 `1`）；
   - 循环取出当前最高位数字 `d = n / tmp`，根据 `tmp` 的值分派输出：`100` 打印 `d` 个 `B`，`10` 打印 `d` 个 `S`，`1`（`< 10`）依次打印 `1` 到 `d`；
   - 更新 `n %= tmp; tmp /= 10;` 直至结束。这种写法天然适配任意 1～3 位数且不输出多余字符。

> [!tip] 固定位数的极简对照写法
> 由于题目明确限定 $n < 1000$，也可直接用三行算术分离各位，再顺序跑三个 `for` 循环（当某位为 `0` 时循环自动执行 0 次，无需判断位数）：
> ```c
> int b = n / 100, s = n / 10 % 10, g = n % 10;
> for (int i = 0; i < b; i++) putchar('B');
> for (int i = 0; i < s; i++) putchar('S');
> for (int i = 1; i <= g; i++) printf("%d", i);
> ```

## 完整源码

```c
/*
让我们用字母B来表示“百”、字母S表示“十”，用“12...n”来表示个位数字n（<10），换个格式来输出任一个不超过3位的正整数。
例如234应该被输出为BBSSS1234，因为它有2个“百”、3个“十”、以及个位的4。
输入格式：每个测试输入包含1个测试用例，给出正整数n（<1000）。
输出格式：每个测试用例的输出占一行，用规定的格式输出n。
输入样例1：
234
输出样例1：
BBSSS1234
输入样例2：
23
输出样例2：
SS123
*/
#include <stdio.h>

int weishu(int n);
void read(int n);
int main(){
    int num;
    scanf("%d",&num);
    read(num);
    return 0;
}
int weishu(int n){
    int tmp=1;
    while (n>9){
        n/=10;
        tmp*=10;
    }return tmp;
}
void read(int n){
    int tmp=weishu(n),i;
    while (tmp>0){
        int d=n/tmp;
        switch (tmp)
        {
        case 100:
        for (i=0;i<d;i++)
        {
            printf("B");
        }break;
        case 10:
        for (i=0;i<d;i++)
        {
            printf("S");
        }break;
    }
        if (tmp<10){
            for (i=0;i<d;i++)
            {
            printf("%d",i+1);
            }
        }
        n%=tmp;
        tmp/=10;
    }
}
```
