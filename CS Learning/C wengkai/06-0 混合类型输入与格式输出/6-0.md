> [!abstract] 本题概览
> 顺序读入浮点数 1、整数、字符、浮点数 2，再调整顺序并保留 2 位小数输出。核心细节在于理解 **`scanf` 中 `%c` 不会自动跳过空白字符**，因此格式串里 `%c` 前的空格至关重要。

---

## 题目描述

本题要求编写程序，顺序读入浮点数 1、整数、字符、浮点数 2，再按照字符、整数、浮点数 1、浮点数 2 的顺序输出。

### 输入格式

输入在一行中顺序给出浮点数 1、整数、字符、浮点数 2，其间以 1 个空格分隔。

### 输出格式

在一行中按照字符、整数、浮点数 1、浮点数 2 的顺序输出，其中浮点数保留小数点后 2 位。

### 输入样例

```text
2.12 88 c 4.7
```

### 输出样例

```text
c 88 2.12 4.70
```

---

## 解题思路与核心知识点

1. **`%c` 前的空格决定成败**：
   - 在 `scanf` 中，`%d`、`%lf`、`%s` 都会自动忽略前导空白符（空格、Tab、换行），但**唯独 `%c` 会原样读取下一个任意字符（包括空格）**！
   - 源码写作 `scanf("%lf %d %c %lf", &f1, &a, &b, &f2);`：`%d` 与 `%c` 之间的空格会主动吞掉输入流中的任意空白字符，从而精准读到目标字符 `c`。
2. **输出精度控制**：`%.2f`（C99 起 `printf` 中 `%.2lf` 与 `%.2f` 等价）会将浮点数四舍五入并强制补齐 2 位小数（如 `4.7` 输出为 `4.70`）。

> [!tip] `scanf` 与 `printf` 的 `double` 格式符区别
> - `scanf` 中读 `double` **必须**写 `%lf`（`%f` 只用于 `float`）；
> - `printf` 中 `float` 会默认参数提升为 `double`，因此 `%f` 与 `%lf` 均可输出 `double`，习惯上常写 `%.2f`。

## 完整源码

```c
/*
本题要求编写程序，顺序读入浮点数1、整数、字符、浮点数2，再按照字符、整数、浮点数1、浮点数2的顺序输出。
输入格式：    输入在一行中顺序给出浮点数1、整数、字符、浮点数2，其间以1个空格分隔。
输出格式：    在一行中按照字符、整数、浮点数1、浮点数2的顺序输出，其中浮点数保留小数点后2位。
输入样例：    2.12 88 c 4.7
输出样例：    c 88 2.12 4.70
*/
#include <stdio.h>
int main(){
	double f1=0,f2=0;
	int a=0;
	char b;
	scanf("%lf %d %c %lf",&f1,&a,&b,&f2);
	printf("%c %d %.2lf %.2lf",b,a,f1,f2);
	return 0;
}
```
