## 题目描述

分数可以表示为“分子/分母”的形式。编写一个程序，要求用户输入一个分数，然后将其约分为最简分式。

最简分式是指分子和分母不具有可以约分的成分了，如 `6/12` 可以被约分为 `1/2`。当分子大于分母时，不需要表达为带分数形式，即 `11/8` 还是 `11/8`；而当分子分母相等时，仍然表达为 `1/1` 的分数形式。

### 输入格式

输入在一行中给出一个分数，分子和分母中间以斜杠 `/` 分隔，如：`12/34` 表示 34 分之 12。分子和分母都是正整数（不包含 0）。

提示：在 `scanf` 的格式字符串中加入 `/`，让 `scanf` 来处理这个斜杠。

### 输出格式

在一行中输出这个分数对应的最简分式，格式与输入的相同，即采用“分子/分母”的形式表示分数。如 `5/6` 表示 6 分之 5。

### 输入样例

```text
60/120
```

### 输出样例

```text
1/2
```

---

## 解题思路与核心知识点

1. **格式串解析**：`scanf("%d/%d", &a, &b)` 直接匹配输入中的斜杠 `/`。
2. **辗转相除法（欧几里得算法）**：
   - 基于恒等式 $\gcd(a, b) = \gcd(b, a \bmod b)$，循环执行 `c = a % b; a = b; b = c;` 直到 `b == 0`，此时 `a` 即为最大公约数。
   - **时间复杂度**：$O(\log \min(a, b))$，效率极高；且无需事先比较 $a$ 与 $b$ 的大小（若 $a < b$，首轮取余后自动交换为 $(b, a)$）。
3. **保留原值约分**：因辗转相除会覆盖 `a`、`b`，源码提前保存 `a_0 = a, b_0 = b`，最终输出 `a_0 / a` 与 `b_0 / a` 即可。

## 完整源码

```c
/*
分数可以表示为“分子/分母”的形式。编写一个程序，要求用户输入一个分数，然后将其约分为最简分式。
最简分式是指分子和分母不具有可以约分的成分了。如6/12可以被约分为1/2。
当分子大于分母时，不需要表达为整数又分数的形式，即11/8还是11/8；而当分子分母相等时，仍然表达为1/1的分数形式。
输入格式：
输入在一行中给出一个分数，分子和分母中间以斜杠“/”分隔，如：12/34表示34分之12。分子和分母都是正整数（不包含0，如果不清楚正整数的定义的话）。
提示：在scanf的格式字符串中加入“/”，让scanf来处理这个斜杠。
输出格式：
在一行中输出这个分数对应的最简分式，格式与输入的相同，即采用“分子/分母”的形式表示分数。如5/6表示6分之5。
输入样例：
60/120
输出样例：
1/2
*/
#include <stdio.h>
int main(){
    int a,b,c,gcd;
    scanf("%d/%d",&a,&b);
    int a_0=a,b_0=b;
    while (b!=0){
        c=a%b;
        a=b;
        b=c;
        //辗转相除法
    }
    printf("%d/%d",a_0/a,b_0/a);
    return 0;
}
```
