> [!abstract] 本题概览
> 使用**嵌套结构体**与**结构体数组**存储 $N$（$N \le 10$）条通讯录记录，并根据 $K$ 次下标查询按指定字段顺序输出或返回 `Not Found`。核心练习==嵌套结构体建模、`scanf` 宽度限长防溢出、日期分隔符解析与补零格式化输出==。

## 题目描述

通讯录中的一条记录包含下述基本信息：朋友的姓名、出生日期、性别、固定电话号码、移动电话号码。本题要求编写程序，录入 $N$ 条记录，并且根据要求显示任意某条记录。

### 输入格式

输入在第 1 行给出正整数 $N$（$N \le 10$）；随后 $N$ 行，每行按照格式 `姓名 生日 性别 固话 手机` 给出一条记录。其中：
- **姓名**：不超过 10 个字符、不包含空格的非空字符串；
- **生日**：按 `yyyy/mm/dd` 的格式给出年月日；
- **性别**：用 `M` 表示男、`F` 表示女；
- **固话**与**手机**：均为不超过 15 位的连续数字，前面有可能出现 `+`。

在通讯录记录输入完成后，最后一行给出正整数 $K$，并且随后给出 $K$ 个整数，表示要查询的记录编号（从 `0` 到 `N - 1` 顺序编号），数字间以空格分隔。

### 输出格式

对每一条要查询的记录编号，在一行中按照 `姓名 固话 手机 性别 生日` 的格式输出该记录。若要查询的记录不存在，则输出 `Not Found`。

### 输入样例

```text
3
Chris 1984/03/10 F +86181779452 13707010007
LaoLao 1967/11/30 F 057187951100 +8618618623333
QiaoLin 1980/01/01 M 84172333 10086
2 1 7
```

### 输出样例

```text
LaoLao 057187951100 +8618618623333 F 1967/11/30
Not Found
```

## 解题思路与核心知识点

### 1. 嵌套结构体与字段空间规划

源码在 `struct friend` 中嵌套定义了日期结构体 `struct date birth`，结构体数组 `struct friend list[10]` 存放全部联系人：

| 字段 | 声明类型 | 数组长度设计依据 | 读写格式符 |
| --- | --- | --- | --- |
| 姓名 | `char name[11]` | 最多 10 字符 + 1 字节 `'\0'` | `scanf("%10s", ...)` |
| 生日 | `struct date { int year, month, day; }` | 直接按整数拆分，自动适配 `/` 分隔 | 输入 `%d/%d/%d`；输出 ==`%04d/%02d/%02d`== |
| 性别 | `char sex` | 单个字符 `'M'` 或 `'F'` | ==`scanf(" %c", ...)`==（前置空格跳过空白） |
| 固话 / 手机 | `char tele[17]`, `char mobile[17]` | 最多 15 位数字 + 可选前导 `'+'`（共 16 字符）+ `'\0'` | `scanf("%16s", ...)` |

### 2. 四处精彩的 `scanf` / `printf` 细节

1. **带宽度限制的 `%10s` / `%16s`**：防止超长异常输入踩穿数组边界（缓冲区溢出）。
2. **`" %c"` 的前置空格**：`%c` 与 `%d`/`%s` 不同，**不会自动跳过空白字符**！若漏写前导空格，会直接读到生日与性别之间的 `' '` 空格字符。
3. **`%d/%d/%d` 字面量匹配**：格式串中的 `/` 直接消费输入中的斜杠分隔符。
4. **`%04d/%02d/%02d` 零填充**：用 `%d` 读入 `03` 后整数变为 `3`，输出时必须指定宽度与 `0` 填充标志才能还原为 `1984/03/10`。

### 3. 复杂度与边界陷阱

- **时间复杂度**：$O(N + K)$，每次查询通过数组下标直接 $O(1)$ 随机访问。
- **空间复杂度**：$O(N)$。

> [!warning] 负数查询编号的下界检查！
> 源码第 43 行的有效编号判断仅写了 `if (i < N)`，**遗漏了下界 `i >= 0`**。如果测试用例查询 `-1` 等负数编号，`i < N` 会成立并导致数组负下标越界访问（未定义行为）！完整判断应写为：
> ```c
> if (i >= 0 && i < N) { ... }
> ```
> 此外注意输出字段顺序与输入顺序不同：输入是 `姓名 生日 性别 固话 手机`，输出是 `姓名 固话 手机 性别 生日`。

## 完整源码

```c
/*
通讯录中的一条记录包含下述基本信息：朋友的姓名、出生日期、性别、固定电话号码、移动电话号码。
本题要求编写程序，录入N条记录，并且根据要求显示任意某条记录。
输入格式：
输入在第1行给出正整数N（<=10）；随后N行，每行按照格式“姓名 生日 性别 固话 手机”给出一条记录。
其中“姓名”是不超过10个字符、不包含空格的非空字符串；生日按“yyyy/mm/dd”的格式给出年月日；性别用“M”表示“男”、“F”表示“女”；
“固话”和“手机”均为不超过15位的连续数字，前面有可能出现“+”。
在通讯录记录输入完成后，最后一行给出正整数K，并且随后给出K个整数，表示要查询的记录编号（从0到N-1顺序编号）。数字间以空格分隔。
输出格式：
对每一条要查询的记录编号，在一行中按照“姓名 固话 手机 性别 生日”的格式输出该记录。若要查询的记录不存在，则输出“Not Found”。
输入样例：
3
Chris 1984/03/10 F +86181779452 13707010007
LaoLao 1967/11/30 F 057187951100 +8618618623333
QiaoLin 1980/01/01 M 84172333 10086
2 1 7
输出样例：
LaoLao 057187951100 +8618618623333 F 1967/11/30
Not Found
*/
#include <stdio.h>
#include <string.h>
struct friend {
    char name[11],tele[17],mobile[17],sex;
    struct date{
        int year,month,day;
    }birth;
};
int main(){
    int N,K,i,j;
    scanf("%d",&N);
    struct friend list[10];
    for (i=0;i<N;i++){
        scanf("%10s", list[i].name);
        scanf("%d/%d/%d",&list[i].birth.year,&list[i].birth.month,&list[i].birth.day);
        scanf(" %c",&list[i].sex);
        scanf("%16s",list[i].tele);
        scanf("%16s",list[i].mobile);
    }
    scanf("%d",&K);
    for (j=0;j<K;j++){
        scanf("%d",&i);
        if (i<N){
            printf("%s %s %s %c %04d/%02d/%02d\n",
                list[i].name,list[i].tele,list[i].mobile,list[i].sex,
                list[i].birth.year,list[i].birth.month,list[i].birth.day);
        }
        else {
            printf("Not Found\n");
        }
    }
    return 0;
}
```
