## 题目描述

输入一个字符串和一个非负整数 $N$，要求将字符串循环左移 $N$ 次。

### 输入格式

输入在第 1 行中给出一个不超过 100 个字符长度的、以回车结束的非空字符串；第 2 行给出非负整数 $N$。

### 输出格式

在一行中输出循环左移 $N$ 次后的字符串。

### 输入样例

```text
Hello World!
2
```

### 输出样例

```text
llo World!He
```

---

## 解题思路与核心知识点

### 1. 取模归一化与分段拼接

循环左移 `len` 次等价于回到原串，因此第一步必须先执行 ==`n %= len`==（处理 $N \ge \text{len}$ 的情况，防止指针 `a + n` 越界！）。

随后将原串按位置 `n` 切分为前缀 $A = \text{a}[0 \dots n-1]$ 与后缀 $B = \text{a}[n \dots \text{len}-1]$，目标即拼接为 $B + A$：

```mermaid
flowchart LR
    ORIG["原串 a: [He | llo World!] (len=12, n=2)"]
    S1["1. strcpy(ret, a + n) -> 写入后缀 llo World!"]
    S2["2. *(a + n) = '\\0' -> 截断前缀 He"]
    S3["3. strcpy(ret + len - n, a) -> 拼接前缀 He"]
    RES["结果 ret: llo World!He"]
    ORIG --> S1 --> S2 --> S3 --> RES
```

- **时间复杂度**：$O(\text{len})$，两次线性拷贝即可完成。
- **空间复杂度**：$O(\text{len})$，借助结果数组 `char ret[101]`。

> [!tip] 经典 $O(1)$ 额外空间解法：三次反转法（Reverse Algorithm）
> 若要求不额外开辟 `ret` 数组、直接在原串上原地循环左移 $n$ 位，可利用对称性公式 $(A^R B^R)^R = BA$：
> 1. 反转前缀 `a[0 .. n-1]`：`"He"` → `"eH"`
> 2. 反转后缀 `a[n .. len-1]`：`"llo World!"` → `"!dlroW oll"`
> 3. 反转整个字符串 `a[0 .. len-1]`：`"eH!dlroW oll"` → `"llo World!He"`
>
> **边界检查**：当 `n % len == 0` 时，本源码中 `strcpy(ret, a + 0)` 完整拷贝原串，接着 `*(a + 0) = '\0'` 将 `a` 置为空串，`strcpy(ret + len, a)` 在 `ret[len]` 处补 `'\0'`，结果依然正确。

## 完整源码

```c
/*
输入一个字符串和一个非负整数N，要求将字符串循环左移N次。
输入格式：
输入在第1行中给出一个不超过100个字符长度的、以回车结束的非空字符串；第2行给出非负整数N。
输出格式：
在一行中输出循环左移N次后的字符串。
输入样例：
Hello World!
2
输出样例：
llo World!He
*/
#include <stdio.h>
#include <string.h>
int main(){
    char a[101],*p=a,s1,ret[101];
    int n;
    while ((s1=getchar())!='\n'){
        *p=s1;
        p++;
    }
    *p='\0';
    int len=strlen(a);
    scanf("%d",&n);
    n%=len;
    strcpy(ret,a+n);
    *(a+n)='\0';
    strcpy(ret+len-n,a);
    printf("%s",ret);
    return 0;
}
```
