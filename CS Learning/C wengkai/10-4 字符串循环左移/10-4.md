## 题目与学习笔记

输入一个字符串和一个非负整数N，要求将字符串循环左移N次。

### 输入格式

输入在第1行中给出一个不超过100个字符长度的、以回车结束的非空字符串；第2行给出非负整数N。

### 输出格式

在一行中输出循环左移N次后的字符串。

### 输入样例

```text
Hello World!
2
```

### 输出样例

```text
llo World!He
```

## 完整源码

```c
/*
输入一个字符串和一个非负整数N，要求将字符串循环左移N次。
输入格式：
输入在第1行中给出一个不超过100个字符长度的、以回车结束的非空字符串；第2行给出非负整数N。
输出格式：
在一行中输出循环左移N次后的字符串。
输入样例：
Hello World!
2
输出样例：
llo World!He
*/
#include <stdio.h>
#include <string.h>
int main(){
    char a[101],*p=a,s1,ret[101];
    int n;
    while ((s1=getchar())!='\n'){
        *p=s1;
        p++;
    }
    *p='\0';
    int len=strlen(a);
    scanf("%d",&n);
    n%=len;
    strcpy(ret,a+n);
    *(a+n)='\0';
    strcpy(ret+len-n,a);
    printf("%s",ret);
    return 0;
}
```
