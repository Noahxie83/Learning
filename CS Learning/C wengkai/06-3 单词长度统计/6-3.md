> [!abstract] 本题概览
> 读入以 `.` 结尾的一行文本，输出以一个或多个空格分隔的每个单词的长度，行末不留空格。核心在于用逐字符状态机处理**连续空格跳过**与**行末句号收尾**。

---

## 题目描述

你的程序要读入一行文本，其中以空格分隔为若干个单词，以 `.` 结束。你要输出每个单词的长度。

这里的单词与语言无关，可以包括各种符号，比如 `it's` 算一个单词，长度为 4。注意，行中可能出现连续的空格；最后的 `.` 不计算在内。

### 输入格式

输入在一行中给出一行文本，以 `.` 结束。

提示：用 `scanf("%c", ...);` 来读入一个字符，直到读到 `.` 为止。

### 输出格式

在一行中输出这行文本对应的单词的长度，每个长度之间以空格隔开，行末没有最后的空格。

### 输入样例

```text
It's great to see you here.
```

### 输出样例

```text
4 5 2 3 3 4
```

---

## 解题思路与核心知识点

1. **逐字符计数逻辑**：
   - 用计数器 `tmp` 记录当前正在扫描的单词长度；
   - 读到非空格、非句号字符时 `tmp++`；
   - 读到空格时，仅当 `tmp != 0` 才说明刚结束一个单词，输出其长度并将 `tmp` 清零；若 `tmp == 0` 则属于连续空格（或行首空格），直接跳过。
   - **原始学习备注保留**：源码第 29–31 行注释记录了 `else { continue; } 可以加上便于理解`，强调 `tmp == 0` 遇到空格时什么也不做的空分支语义。

> [!warning] 原源码输出格式的两处隐患复盘
> 1. **缺少单词长度间的空格**：源码中的 `printf("%d", tmp);` 未打印分隔空格，样例 `It's great to see you here.` 会连在一起输出成 `452334`。
> 2. **句号前有空格或空文本 `.`**：当输入为 `hello .` 或 `.` 时，遇到 `.` 时 `tmp == 0`，源码未判断 `tmp > 0` 会多输出一个 `0`。
>
> **完整 AC 修正思路**：增设标志位 `int first = 1;`——每当确认输出一个单词（`tmp > 0`）时，若 `!first` 先打印一个空格，再打印 `tmp` 并令 `first = 0`；遇到 `.` 时同样只在 `tmp > 0` 时输出，这样同时完美解决**分隔空格、行末无空格、连续空格、句号前空格与空句 `.`** 全部边界。

## 完整源码

```c
/*
你的程序要读入一行文本，其中以空格分隔为若干个单词，以‘.’结束。你要输出每个单词的长度。
这里的单词与语言无关，可以包括各种符号，比如“it's”算一个单词，长度为4。
注意，行中可能出现连续的空格；最后的‘.’不计算在内。
输入格式： 输入在一行中给出一行文本，以‘.’结束。
提示：用scanf("%c",...);来读入一个字符，直到读到‘.’为止。
输出格式：   在一行中输出这行文本对应的单词的长度，每个长度之间以空格隔开，行末没有最后的空格。
输入样例：   It's great to see you here.
输出样例：   4 5 2 3 3 4
*/
#include <stdio.h>
int main(){
    char ch='0';
    int tmp=0;
    while (ch!='.'){
        scanf("%c",&ch);
        if (ch=='.'){
            printf("%d",tmp);
            break;
        }
        else if (ch!=' '){
            tmp++;
        }
        else if (ch==' '){
            if(tmp!=0){
                printf("%d",tmp);
                tmp=0;
            }
        }/*else{
        continue;}
        可以加上便于理解*/
    }
    return 0;
}
```
