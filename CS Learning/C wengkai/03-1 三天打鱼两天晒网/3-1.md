> [!abstract] 本题概览
> 给定正整数 $N$，按照“3 天打鱼、2 天晒网”的 5 天周期判断第 $N$ 天的状态。核心知识点是**利用取模运算 `% 5` 将无限日期映射到有限周期**，同时需注意多条件逻辑与 `&&` 的正确组合。

---

## 题目描述

中国有句俗语叫“三天打鱼两天晒网”。假设某人从某天起，开始“三天打鱼两天晒网”，问这个人在以后的第 $N$ 天中是“打鱼”还是“晒网”？

### 输入格式

输入在一行中给出 1 个不超过 1000 的正整数 $N$。

### 输出格式

在一行中输出此人在第 $N$ 天中是 `Fishing`（即“打鱼”）还是 `Drying`（即“晒网”），并且输出 `in day N`。

### 输入样例 1

```text
103
```

### 输出样例 1

```text
Fishing in day 103
```

### 输入样例 2

```text
34
```

### 输出样例 2

```text
Drying in day 34
```

---

## 解题思路与核心知识点

1. **周期映射表**：周期长度为 $3 + 2 = 5$，将 $N \bmod 5$ 的 5 种余数逐一对应：

| $N \bmod 5$ | 对应周期内第几天 | 当天状态 |
| :---: | :---: | --- |
| `1` | 第 1 天 | `Fishing` |
| `2` | 第 2 天 | `Fishing` |
| `3` | 第 3 天 | `Fishing` |
| `4` | 第 4 天 | `Drying` |
| `0` | 第 5 天 | `Drying` |

2. **判断逻辑**：当 `N % 5 >= 1 && N % 5 <= 3`（即余数为 1、2、3）时输出 `Fishing`，否则（余数为 0 或 4）输出 `Drying`。

> [!warning] 原源码逻辑 Bug 复盘
> 原始 `3-1.c` 将条件拆写成了 `if (N%5>=1)` 和 `else if (N%5<=3)`：
> - 当余数为 `4` 时，满足 `N % 5 >= 1` 进入第一个分支，误判为 `Fishing`；
> - 当余数为 `0` 时，不满足 `>= 1`，却满足第二个分支 `N % 5 <= 3`，同样误判为 `Fishing`！
> 结果导致 `else` 中的 `Drying` **永远不会执行**。
>
> **修正写法**：必须使用逻辑与 `&&` 将区间上下界合并在同一个条件里：
> ```c
> int r = N % 5;
> if (r >= 1 && r <= 3) {
>     printf("Fishing in day %d", N);
> } else {
>     printf("Drying in day %d", N);
> }
> ```

## 完整源码

```c
/*
中国有句俗语叫“三天打鱼两天晒网”。假设某人从某天起，开始“三天打鱼两天晒网”，问这个人在以后的第N天中是“打鱼”还是“晒网”？
输入格式：    输入在一行中给出1个不超过1000的正整数N。
输出格式：    在一行中输出此人在第N天中是“Fishing”（即“打鱼”）还是“Drying”（即“晒网”），并且输出“in day N”。
输入样例1：   103
输出样例1：   Fishing in day 103
输入样例2：   34
输出样例2：   Drying in day 34
*/
#include <stdio.h>
int main(){
    int N;
    scanf("%d", &N);
    if (N%5>=1){
        printf("Fishing in day %d", N);
    }
    else if(N%5<=3){
        printf("Fishing in day %d", N);
    }
    else{
        printf
            ("Drying in day %d", N);}
    return 0;
}
```
