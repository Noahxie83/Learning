> [!abstract] 本题概览
> 输入一位数字 $a \in [0, 9]$ 与项数 $n \in [1, 8]$，求数列 $S = a + aa + aaa + \dots + \underbrace{aa\dots a}_{n\text{ 个 }a}$ 之和。利用递推公式 $t_k = 10 t_{k-1} + a$ 线性累积，无需调用浮点 `pow()`。

---

## 题目描述

输入两个整数 $a$ 和 $n$，$a$ 的范围是 $[0, 9]$，$n$ 的范围是 $[1, 8]$，求数列之和 $S = a + aa + aaa + \dots + aaa\dots a$（$n$ 个 $a$）。

如 $a$ 为 `2`、$n$ 为 `8` 时输出的是 $2 + 22 + 222 + \dots + 22222222$ 的和。

### 输入格式

输入在一行中给出两个整数，先后表示 $a$ 和 $n$。

### 输出格式

在一行中输出要求的数列之和。

### 输入样例

```text
2 4
```

### 输出样例

```text
2468
```

---

## 解题思路与核心知识点

1. **线性递推构造每一项**：
   - 设当前项为 `tmp`（初值 `0`），每轮循环执行 `tmp = tmp * 10 + a; sum += tmp;`；
   - 以 `a = 2, n = 4` 为例，`tmp` 依次为 `2 → 22 → 222 → 2222`，总和 `sum = 2468`。
   - **复杂度**：时间 $O(n)$，空间 $O(1)$；当 $a = 9, n = 8$ 时最大和约为 $1.1 \times 10^8$，完全在 32 位 `int` 表示范围内，不会溢出。

> [!warning] 源码头文件缺失提醒
> 原始 `5-3.c` 文件顶部漏写了 `#include <stdio.h>`。在旧版 C89 编译器下可能仅报隐式声明警告而勉强通过，但在严格 C99/C11/C17 编译模式下会直接报错。标准写法务必在首行补上 `#include <stdio.h>`。

## 完整源码

```c
/*
输入两个整数a和n，a的范围是[0,9]，n的范围是[1,8]，求数列之和S = a+aa+aaa+...+aaa...a（n个a）。
如a为2、n为8时输出的是2+22+222+...+22222222的和。
输入格式：    输入在一行中给出两个整数，先后表示a和n。
输出格式：    在一行中输出要求的数列之和。
输入样例：    2 4
输出样例：    2468
*/
int main(){
    int a,n;
    scanf ("%d %d",&a,&n);
    int sum=0,tmp=0;
    while (n>0){
        tmp=tmp*10+a;
        sum+=tmp;
        n--;
    }
    printf("%d",sum);
return 0;
}
```
