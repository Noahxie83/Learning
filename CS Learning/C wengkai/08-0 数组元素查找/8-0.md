> [!abstract] 本题概览
> 在给定的 $N$（$N \le 20$）个整数中顺序查找目标值 $X$，命中时输出其从 0 开始的下标，否则输出 `Not Found`。核心练习==一维数组遍历、在线边读边查与未命中边界判断==。

---

## 题目描述

本题要求从输入的 $N$ 个整数中查找给定的 $X$。如果找到，输出 $X$ 的位置（从 0 开始数）；如果没有找到，输出 `Not Found`。

### 输入格式

输入在第 1 行中给出 2 个正整数 $N$（$N \le 20$）和 $X$，第 2 行给出 $N$ 个整数。数字均不超过长整型，其间以空格分隔。

### 输出格式

在一行中输出 $X$ 的位置，或者 `Not Found`。

### 输入样例 1

```text
5 7
3 5 7 1 9
```

### 输出样例 1

```text
2
```

### 输入样例 2

```text
5 7
3 5 8 1 9
```

### 输出样例 2

```text
Not Found
```

---

## 解题思路与核心知识点

### 1. 线性查找逻辑

源码采用**边读入边匹配**的策略：

1. 读入元素总数 $N$ 与目标值 $x$。
2. 循环 `i = 0` 到 `N - 1`，每次读入一个数存入 `a[i]`，同时判断是否满足 `j == x`：
   - 若相等，立即输出下标 `i` 并执行 `break` 提前结束循环；
   - 若走到最后一个元素 `i == N - 1` 仍未触发 `break`，说明整个序列中不存在 $x$，输出 `Not Found`。

- **时间复杂度**：最坏 $O(N)$，最好 $O(1)$（首元素即命中）。
- **空间复杂度**：$O(N)$（源码开 `a[20]` 练习数组存值；若无需回溯数组，也可直接用单个变量达到 $O(1)$）。

> [!warning] 两个值得注意的工程细节
> 1. **“长整型”的数据类型**：题面说明“数字均不超过长整型”。在 64 位 Linux（LP64）中 `long` 为 64 位，而 Windows（LLP64）中 `long` 仅为 32 位；为确保跨平台不溢出，更稳妥的做法是统一用 `long long`（`%lld`）。
> 2. **提前 `break` 与标志位解耦**：单组测试下找到后直接 `break` 没有问题；但在多组测试场景中，若未读完当前行剩余数字就 `break`，残留数据会污染下一组 `scanf`。更通用的写法是读完所有元素后，用 `int pos = -1;` 标记首次命中位置，循环结束后统一判断是否输出 `Not Found`。

## 完整源码

```c
/*
本题要求从输入的N个整数中查找给定的X。如果找到，输出X的位置（从0开始数）；如果没有找到，输出“Not Found”。
输入格式：
输入在第1行中给出2个正整数N（<=20）和X，第2行给出N个整数。数字均不超过长整型，其间以空格分隔。
输出格式：
在一行中输出X的位置，或者“Not Found”。
输入样例1：
5 7
3 5 7 1 9
输出样例1：
2
输入样例2：
5 7
3 5 8 1 9
输出样例2：
Not Found
*/
#include <stdio.h>
int main(){
    int N,x,i,j;
    int a[20];
    scanf("%d %d",&N,&x);
    for (i=0;i<N;i++){
        scanf("%d",&j);
        a[i]=j;
    if (j==x){
        printf("%d",i);
        break;
    }
    if (i==N-1){
        printf("Not Found");
    }
    }
    return 0;
}
```
