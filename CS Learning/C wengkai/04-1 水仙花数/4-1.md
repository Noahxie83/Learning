## 题目描述

水仙花数是指一个 $N$ 位正整数（$N \ge 3$），它的每个位上的数字的 $N$ 次幂之和等于它本身。

例如：$153 = 1^3 + 5^3 + 3^3$。本题要求编写程序，计算所有 $N$ 位水仙花数。

### 输入格式

输入在一行中给出一个正整数 $N$（$3 \le N \le 7$）。

### 输出格式

按递增顺序输出所有 $N$ 位水仙花数，每个数字占一行。

### 输入样例

```text
3
```

### 输出样例

```text
153
370
371
407
```

---

## 解题思路与核心知识点

1. **空间换时间——预计算幂表**：
   - 在尚未学习数组之前，源码用 10 个独立变量 `p0`–`p9` 在枚举前一次性算出 $0^N, 1^N, \dots, 9^N$；
   - 随后利用循环结束后 `i == N` 的状态顺手反推下界 `start = 10^{N-1}` 与上界 `end = start * 10 - 1`。
2. **两个版本性能对比**：

| 实现版本 | 幂计算方式 | 时间复杂度 | $N = 7$ 表现 |
| --- | --- | :---: | --- |
| [[CS Learning/C wengkai/04-1 水仙花数（教师版本）/4-1-teacher's version\|教师版本]] | 每次拆位现场连乘 $N$ 次 | $O(N^2 \cdot 10^{N-1})$ | 重复乘法极多，耗时明显偏长 |
| **本版本（预计算）** | 预先算出 `p0`–`p9`，循环内直接累加 | ==$O(N \cdot 10^{N-1})$== | 消除最内层循环，速度快数倍 |

> [!tip] 学完数组后的进一步重构
> 掌握数组后，可以将 `p0..p9` 和 10 个 `if / else if` 分支合并为 `int p[10];` 与一行 `sum += p[dig];`，不仅代码更短，还能避免分支预测开销，性能再进一步。

## 完整源码

```c
/*
水仙花数是指一个N位正整数（N>=3），它的每个位上的数字的N次幂之和等于它本身。
例如：153 = 1^3 + 5^3+ 3^3。本题要求编写程序,计算所有N位水仙花数。
输入格式：    输入在一行中给出一个正整数N（3<=N<=7）。
输出格式：    按递增顺序输出所有N位水仙花数，每个数字占一行。
输入样例：    3
输出样例：
153
370
371
407
*/
#include <stdio.h>
int main(){
    int N;
    scanf("%d" ,&N);
    int i=0,p0=1,p1=1,p2=1,p3=1,p4=1;
    int p5=1,p6=1,p7=1,p8=1,p9=1;
    while(i<N){
        p0*=0;
        p1*=1;
        p2*=2;
        p3*=3;
        p4*=4;
        p5*=5;
        p6*=6;
        p7*=7;
        p8*=8;
        p9*=9;
        i++;
    }
    int start=1;
    while(i-1>0){
        start*=10;
        i--;
    }
    int end=start*10-1,x_0=start,x;
    while(x_0<=end){
        int sum=0,x=x_0;
        while(x>0){
        int dig=x%10;
        if(dig==0) sum+=p0;
            else if(dig==1) sum+=p1;
            else if(dig==2) sum+=p2;
            else if(dig==3) sum+=p3;
            else if(dig==4) sum+=p4;
            else if(dig==5) sum+=p5;
            else if(dig==6) sum+=p6;
            else if(dig==7) sum+=p7;
            else if(dig==8) sum+=p8;
            else if(dig==9) sum+=p9;
            x/=10;
        }
        if (x_0==sum){
            printf("%d\n",x_0);
        }
        x_0++;
    }
    return 0;
}
```
