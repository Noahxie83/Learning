> [!abstract] 本题概览
> 统计 $N$（$N \le 1000$）个正整数中 `0`–`9` 每个数字出现的总频次，按 `M: n1 n2 ...` 格式升序输出出现次数最多的所有数字。核心技巧为==定长桶计数数组 `count[10]`、逐位取模拆解与无尾随空格输出==。

---

## 题目描述

给定一批整数，分析每个整数的每一位数字，求出现次数最多的个位数字。

例如给定 3 个整数 `1234`、`2345`、`3456`，其中出现最多次数的数字是 `3` 和 `4`，均出现了 3 次。

### 输入格式

输入在第 1 行中给出正整数 $N$（$N \le 1000$），在第 2 行中给出 $N$ 个不超过整型范围的正整数，数字间以空格分隔。

### 输出格式

在一行中按格式 `M: n1 n2 ...` 输出，其中 $M$ 是最大次数，$n_1, n_2, \dots$ 为出现次数最多的个位数字，按从小到大的顺序排列。数字间以空格分隔，但末尾不得有多余空格。

### 输入样例

```text
3
1234 2345 3456
```

### 输出样例

```text
3: 3 4
```

---

## 解题思路与核心知识点

### 1. 三步桶计数流程

1. **初始化桶数组**：定义 `int count[10] = {0};`，下标 `0..9` 直接映射十进制数字 `0` 到 `9`。
2. **逐位拆解并累加**：对每个输入的正整数 $k$，循环执行 `dig = k % 10; count[dig]++; k /= 10;` 直到 `k == 0`。
3. **求最大值并升序输出**：
   - 先扫描 `count[0..9]` 找到最大频次 `max`；
   - 先打印 `"%d:"`，再从 `i = 0` 到 `9` 升序扫描，凡满足 `count[i] == max` 就打印 `" %d"`。

> [!tip] “前置空格”技巧消除尾随空格
> 题目要求格式为 `M: n1 n2 ...` 且行末无空格。由于先输出了 `M:`，后续每个满足条件的数字统一输出 `" %d"`（空格在前），既保证了顺序升序，又天然避免了行末多余空格！

### 2. 复杂度与边界提醒

- **时间复杂度**：$O(N \log_{10} V)$，其中 $V$ 为单个整数最大值（32 位 `int` 最多拆解 10 次）。
- **空间复杂度**：$O(1)$，仅需长度为 10 的固定数组。

> [!warning] 输入含 `0` 时的边界陷阱
> 本题明确保证输入为**正整数**，因此 `while (k > 0)` 完全正确。如果题目改为允许输入整数 `0`，`while (k > 0)` 会一次都不执行而漏计数字 `0`，此时应改为 `do { count[k % 10]++; k /= 10; } while (k > 0);`。

## 完整源码

```c
/*
给定一批整数，分析每个整数的每一位数字，求出现次数最多的个位数字。
例如给定3个整数1234、2345、3456，其中出现最多次数的数字是3和4，均出现了3次。
输入格式：
输入在第1行中给出正整数N（<=1000），在第2行中给出N个不超过整型范围的正整数，数字间以空格分隔。
输出格式：
在一行中按格式“M: n1 n2 ...”输出，其中M是最大次数，n1、n2、……为出现次数最多的个位数字，
按从小到大的顺序排列。数字间以空格分隔，但末尾不得有多余空格。
输入样例：
3
1234 2345 3456
输出样例：
3: 3 4
*/
#include <stdio.h>

int main(){
    int N,i,k,dig,max;
    int count[10]={0};
    scanf("%d",&N);
    for(i=0;i<N;i++){
        scanf("%d",&k);
        while(k>0){
            dig=k%10;
            count[dig]++;
            k/=10;
        }
    }
    max=count[0];
    for(i=1;i<10;i++){
        if(count[i]>max){
            max=count[i];
        }
    }
    printf("%d:",max);
    for(i=0;i<10;i++){
        if(count[i]==max){
            printf(" %d",i);
        }
    }
    return 0;
}
```
