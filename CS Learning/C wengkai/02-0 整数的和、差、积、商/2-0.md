> [!abstract] 本题概览
> 读入两个正整数 $A$ 和 $B$，按固定格式依次输出它们的和、差、积、商。核心考点为 `scanf` / `printf` 基本格式化读写以及 C 语言中**整数除法的向零截断**特性。

---

## 题目描述

本题要求编写程序，计算 2 个正整数的和、差、积、商并输出。题目保证输入和输出全部在整型范围内。

### 输入格式

输入在一行中给出 2 个正整数 $A$ 和 $B$。

### 输出格式

在 4 行中按照格式 `A 运算符 B = 结果` 顺序输出和、差、积、商。

### 输入样例

```text
3 2
```

### 输出样例

```text
3 + 2 = 5
3 - 2 = 1
3 * 2 = 6
3 / 2 = 1
```

---

## 解题思路与核心知识点

1. **标准格式化输入输出**：使用 `scanf("%d %d", &a, &b)` 读入两个 `int` 整型变量（注意取地址符 `&` 不可遗漏），再用 `printf` 按模板逐行输出。
2. **整数除法截断**：当 `/` 运算符两侧均为整型操作数时，C 语言执行**整型除法**，结果直接丢弃小数部分（如 `3 / 2 = 1`）。本题输出样例要求正是整型商，因此直接写 `a / b` 即可。

> [!tip] 浮点除法对照
> 若日后需要保留小数商，必须将至少一个操作数转为浮点型，例如 `(double)a / b` 或 `1.0 * a / b`，并配合 `%f` / `%.2f` 输出。

## 完整源码

```c
/*
本题要求编写程序，计算2个正整数的和、差、积、商并输出。题目保证输入和输出全部在整型范围内。
输入格式：      输入在一行中给出2个正整数A和B。
输出格式：      在4行中按照格式“A 运算符  B = 结果”顺序输出和、差、积、商。
输入样例：     3 2
输出样例：
3 + 2 = 5
3 - 2 = 1
3 * 2 = 6
3 / 2 = 1
*/
#include <stdio.h>
int main(){
	int a,b;
	scanf("%d %d",&a,&b);
	printf("%d + %d = %d\n",a,b,a+b);
	printf("%d - %d = %d\n",a,b,a-b);
	printf("%d * %d = %d\n",a,b,a*b);
	printf("%d / %d = %d\n",a,b,a/b);
	return 0;
}
```
