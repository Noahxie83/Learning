## 题目描述

给定区间 $[-2^{31}, 2^{31}]$ 内的 3 个整数 $A$、$B$ 和 $C$，请判断 $A + B$ 是否大于 $C$。

### 输入格式

输入第 1 行给出正整数 $T$（$T \le 10$），是测试用例的个数。随后给出 $T$ 组测试用例，每组占一行，顺序给出 $A$、$B$ 和 $C$。整数间以空格分隔。

### 输出格式

对每组测试用例，在一行中输出 `Case #X: true`（如果 $A + B > C$），否则输出 `Case #X: false`，其中 $X$ 是测试用例的编号（从 1 开始）。

### 输入样例

```text
4
1 2 3
2 3 4
2147483647 0 2147483646
0 -2147483648 -2147483647
```

### 输出样例

```text
Case #1: false
Case #2: true
Case #3: true
Case #4: false
```

---

## 解题思路与核心知识点

### 1. 数据类型选择与溢出分析

| 整型类型 | 常见位宽 | 取值范围 | 能否覆盖本题运算 |
| --- | :---: | --- | --- |
| `int` | 32 位 | $[-2^{31},\; 2^{31}-1]$ | 否：$2^{31}$ 本身越界，且 $A + B$ 可达 $\pm 2^{32}$ |
| `long long` | 64 位 | $[-2^{63},\; 2^{63}-1]$ | ==是：轻松容纳 $[-2^{32},\; 2^{32}]$，无溢出风险== |

> [!warning] 有符号整数溢出（Undefined Behavior）
> 在 C 语言中，32 位 `int` 的最大值为 $2^{31} - 1 = 2147483647$。若使用 `int` 读入本题数据，不仅输入值 $2^{31}$ 会直接越界，而且 `2147483647 + 1` 会触发**有符号整数溢出（未定义行为）**并回绕为负数，导致判断结果错误。

### 2. 实现步骤与复杂度

1. 读入测试用例总数 $n$，循环遍历 `i = 0` 到 `n - 1`。
2. 用 `scanf("%lld %lld %lld", &a, &b, &c)` 读入 64 位整数。
3. 调用独立函数 `compare(a, b, c)` 判断 `a + b > c`，返回 `1` 或 `0`。
4. 按 `Case #%d: true/false` 格式输出结果，注意用例编号从 `i + 1` 开始。

- **时间复杂度**：$O(T)$，每组测试仅做常数次比较与输出。
- **空间复杂度**：$O(1)$。

> [!tip] 简化写法参考
> 源码中的 `compare()` 与 `switch` 展示了函数封装与分支控制；在追求简洁时，也可以直接利用条件运算符一行输出：`printf("Case #%d: %s\n", i + 1, (a + b > c) ? "true" : "false");`。

## 完整源码

```c
/*
给定区间[-231, 231]内的3个整数A、B和C，请判断A+B是否大于C。
输入格式：
输入第1行给出正整数T(<=10)，是测试用例的个数。随后给出T组测试用例，每组占一行，顺序给出A、B和C。整数间以空格分隔。
输出格式：
对每组测试用例，在一行中输出“Case #X: true”如果A+B>C，否则输出“Case #X: false”，其中X是测试用例的编号（从1开始）。
输入样例：
4
1 2 3
2 3 4
2147483647 0 2147483646
0 -2147483648 -2147483647
输出样例：
Case #1: false
Case #2: true
Case #3: true
Case #4: false
*/
#include <stdio.h>
int compare(long long a,long long b,long long c);
int main(){
    int n,i;
    long long a,b,c;
    scanf("%d",&n);
    for(i=0;i<n;i++){
        scanf("%lld %lld %lld",&a,&b,&c);
        int judge=compare(a,b,c);
        switch (judge)
        {
        case 1:printf("Case #%d: true\n",i+1);break;
        case 0:printf("Case #%d: false\n",i+1);break;
        }
    }
    return 0;
}
int compare(long long a,long long b,long long c){
    if (a+b>c){
        return 1;
    }
    else {
        return 0;
    }
}
```
