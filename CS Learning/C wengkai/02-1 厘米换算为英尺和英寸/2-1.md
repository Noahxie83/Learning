> [!abstract] 本题概览
> 给定厘米数，利用换算关系 $\text{米} = (\text{foot} + \text{inch} / 12) \times 0.3048$ 反推对应的英尺（`foot`）与英寸（`inch`）整数值。重点在于**浮点与整型之间的混合运算及隐式截断**。

---

## 题目描述

如果已知英制长度的英尺 `foot` 和英寸 `inch` 的值，那么对应的米是 $(\text{foot} + \text{inch} / 12) \times 0.3048$。

现在，如果用户输入的是厘米数，那么对应英制长度的英尺和英寸是多少呢？别忘了 1 英尺等于 12 英寸。

### 输入格式

输入在一行中给出 1 个正整数，单位是厘米。

### 输出格式

在一行中输出这个厘米数对应英制长度的英尺和英寸的整数值，中间用空格分开。

### 输入样例

```text
170
```

### 输出样例

```text
5 6
```

---

## 解题思路与核心知识点

1. **公式反推**：
   - 由于 $1\text{ 米} = 100\text{ 厘米}$，输入厘米数 $h$ 换算为总英尺数为：
     $$\text{total\_foot} = \frac{h / 100}{0.3048} = \frac{h}{30.48}$$
   - 整数部分即为英尺：`foot = height / 30.48;`（赋值给 `int` 时自动舍去小数部分）。
   - 小数部分乘以 12 即为英寸：`inch = (height / 30.48 - foot) * 12;`。
2. **类型转换细节**：`height` 声明为 `double` 并用 `%lf` 读入，保证 `height / 30.48` 始终在双精度浮点下运算；结果赋给 `int foot`、`int inch` 时自动截断取整。

> [!tip] 警惕整数除法陷阱
> 如果将输入声明为 `int cm`，则千万不能写成 `cm / 100 / 0.3048`——因为 `cm / 100` 会先做整型除法（如 `170 / 100 = 1`），导致精度严重丢失！正确写法应为 `cm / 100.0 / 0.3048` 或像源码一样直接除以 `30.48`。

## 完整源码

```c
/*如果已知英制长度的英尺foot和英寸inch的值，那么对应的米是(foot+inch/12)*0.3048。
现在，如果用户输入的是厘米数，那么对应英制长度的英尺和英寸是多少呢？别忘了1英尺等于12英寸。
输入格式：    输入在一行中给出1个正整数，单位是厘米。
输出格式：     在一行中输出这个厘米数对应英制长度的英尺和英寸的整数值，中间用空格分开。
输入样例：  170
输出样例：   5 6
*/
#include <stdio.h>
int main(){
	double height=0;
	scanf("%lf",&height);
	int foot=0,inch=0;
	foot=height/30.48;
	inch=(height/30.48-foot)*12;
	printf ("%d %d",foot,inch);
	return 0;
}
```
