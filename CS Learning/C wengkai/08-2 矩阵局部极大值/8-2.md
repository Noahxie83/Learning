> [!abstract] 本题概览
> 在 $M \times N$（$3 \le M, N \le 20$）整数矩阵中找出所有**严格大于**上下左右四个相邻元素的非边界元素，按行号优先、列号次之递增输出（1 起始编号），不存在时输出 `None M N`。核心考点为==二维数组存储、内层子区域遍历防越界与 0/1 起始坐标换算==。

---

## 题目描述

给定 $M$ 行 $N$ 列的整数矩阵 $A$，如果 $A$ 的非边界元素 `A[i][j]` 严格大于相邻的上下左右 4 个元素，那么就称元素 `A[i][j]` 是矩阵的局部极大值。本题要求找出给定矩阵的全部局部极大值及其所在的位置。

### 输入格式

输入在第 1 行中给出矩阵 $A$ 的行数 $M$ 和列数 $N$（$3 \le M, N \le 20$）；随后 $M$ 行，每行给出 $A$ 在该行的 $N$ 个元素的值，数字间以空格分隔。

### 输出格式

每行按照 `元素值 行号 列号` 的格式输出一个局部极大值，其中行、列编号从 1 开始。要求按照行号递增输出；若同行有超过 1 个局部极大值，则该行按列号递增输出。若没有局部极大值，则输出 `None 总行数 总列数`。

### 输入样例 1

```text
4 5
1 1 1 1 1
1 3 9 3 1
1 5 3 5 1
1 1 1 1 1
```

### 输出样例 1

```text
9 2 3
5 3 2
5 3 4
```

### 输入样例 2

```text
3 5
1 1 1 1 1
9 3 9 9 1
1 5 3 5 1
```

### 输出样例 2

```text
None 3 5
```

---

## 解题思路与核心知识点

### 1. 遍历范围与四邻域比较

矩阵四条边上的元素（第 `0` 行、第 `M - 1` 行、第 `0` 列、第 `N - 1` 列）不完整具备 4 个邻居，题目明确要求仅考察**非边界元素**，因此循环区间自然收缩为：

- 行下标 `i`：`1` 到 `M - 2`（`for (i = 1; i < M - 1; i++)`）
- 列下标 `j`：`1` 到 `N - 2`（`for (j = 1; j < N - 1; j++)`）

这样既保证访问 `A[i-1][j]`、`A[i+1][j]`、`A[i][j-1]`、`A[i][j+1]` **绝对不会数组越界**，又因为外层按 `i` 递增、内层按 `j` 递增，输出顺序自动满足题目要求。

### 2. 关键细节核对

| 检查点 | 正确处理 | 常见错误 |
| --- | --- | --- |
| 大小比较 | 严格大于 `>`（4 个方向全为 `&&`） | 误写为 `>=`（样例 2 中相邻的两个 `9` 均不是局部极大值） |
| 坐标偏移 | 数组 0 起始，输出 `i + 1, j + 1` | 直接输出 `i, j` 导致行列全部少 1 |
| 无解判定 | 计数器 `k == 0` 时输出 `None M N` | 漏记标志位或忘输出总行数、总列数 |

- **时间复杂度**：$O(MN)$，每个内部元素做 4 次比较。
- **空间复杂度**：$O(MN)$（定长 `int A[20][20]`，常数上界 400 个整型）。

## 完整源码

```c
/*
给定M行N列的整数矩阵A，如果A的非边界元素A[i][j]大于相邻的上下左右4个元素，
那么就称元素A[i][j]是矩阵的局部极大值。本题要求给定矩阵的全部局部极大值及其所在的位置。
输入格式：
输入在第1行中给出矩阵A的行数M和列数N（3<=M,N<=20）；最后M行，每行给出A在该行的N个元素的值。数字间以空格分隔。
输出格式：
每行按照“元素值 行号 列号”的格式输出一个局部极大值，其中行、列编号从1开始。要求按照行号递增输出；
若同行有超过1个局部极大值，则该行按列号递增输出。若没有局部极大值，则输出“None 总行数 总列数”。
输入样例1：
4 5
1 1 1 1 1
1 3 9 3 1
1 5 3 5 1
1 1 1 1 1
输出样例1：
9 2 3
5 3 2
5 3 4
输入样例2：
3 5
1 1 1 1 1
9 3 9 9 1
1 5 3 5 1
输出样例2：
None 3 5
*/
#include <stdio.h>
int main(){
    int M,N,i,j,k=0;
    scanf("%d %d",&M,&N);
    int A[20][20]={0};
    for (i=0;i<M;i++){
        for (j=0;j<N;j++){
            scanf("%d",&A[i][j]);
        }
    }
    for (i=1;i<M-1;i++){
        for (j=1;j<N-1;j++){
            if (A[i][j]>A[i-1][j]&&
                A[i][j]>A[i][j-1]&&
                A[i][j]>A[i+1][j]&&
                A[i][j]>A[i][j+1]){
                printf("%d %d %d\n",A[i][j],i+1,j+1);
                k++;
            }
        }
    }
    if (k==0){
        printf("None %d %d\n",M,N);
    }
    return 0;
}
```
