## 题目描述

本题要求编写程序，计算两个二维平面向量的和向量。

### 输入格式

输入在一行中按照 `x1 y1 x2 y2` 的格式给出两个二维平面向量 $V_1 = (x_1, y_1)$ 和 $V_2 = (x_2, y_2)$ 的分量。

### 输出格式

在一行中按照 `(x, y)` 的格式输出和向量，坐标输出小数点后 1 位（注意不能输出 `-0.0`）。

### 输入样例

```text
3.5 -2.7 -13.9 8.7
```

### 输出样例

```text
(-10.4, 6.0)
```

---

## 解题思路与核心知识点

### 1. 结构体定义与点号访问

1. 定义 `struct vector { double x; double y; };`，用 `double` 存储坐标分量以保证足够浮点精度（`scanf` 对应 `%lf`，`printf` 对应 `%.1f`）。
2. 直接通过点号 `.` 访问结构体成员完成输入与分量求和：`ret.x = v1.x + v2.x;`、`ret.y = v1.y + v2.y;`。
3. 相比 [[CS Learning/C wengkai/11-0 二维向量求和（指针与函数版本）/11-0 pointer-function version|指针与函数版本]]，本版直接内联在 `main()` 中，代码更短；而在多处复用向量运算或结构体体积较大时，封装为接受 `struct vector *` 的函数更具可维护性。

### 2. 原始学习注释与边界提醒

| 源码行号 | 对应代码 | 原注释 |
| :---: | --- | --- |
| 29 | `}` | 确保不输出 `-0.0` |

> [!warning] 两个细节提醒
> 1. **消除 `-0.0`**：当结果位于 $(-0.05,\; 0)$ 时，`%.1f` 会四舍五入输出带负号的 `-0.0`；将 `(-0.05, 0.05)` 区间内的分量强制置为 `0.0` 即可杜绝该问题（等价于 `#include <math.h>` 后判断 `fabs(ret.x) < 0.05`）。
> 2. **格式与头文件**：题目输出样例 `(-10.4, 6.0)` 逗号后带一个空格，源码第 30 行 `"(%.1f,%.1f)"` 未含空格，刷题提交时需按具体 OJ 格式要求确认；另外 `<string.h>` 在本程序中未实际使用，可省略。

- **时间复杂度**：$O(1)$；**空间复杂度**：$O(1)$。

## 完整源码

```c
/*
本题要求编写程序，计算两个二维平面向量的和向量。
输入格式：
输入在一行中按照“x1 y1 x2 y2”的格式给出两个二维平面向量V1=(x1, y1)和V2=(x2, y2)的分量。
输出格式：
在一行中按照“(x, y)”的格式输出和向量，坐标输出小数点后1位（注意不能输出-0.0）。
输入样例：
3.5 -2.7 -13.9 8.7
输出样例：
(-10.4, 6.0)
*/
#include <stdio.h>
#include <string.h>
struct vector{
    double x;
    double y;
};
int main(){
    struct vector v1,v2,ret;
    scanf("%lf %lf %lf %lf",
        &v1.x,&v1.y,&v2.x,&v2.y);
    ret.x=v1.x+v2.x;
    ret.y=v1.y+v2.y;
    if(ret.x>-0.05&&ret.x<0.05){
        ret.x=0.0;
    }
    if(ret.y>-0.05&&ret.y<0.05){
        ret.y=0.0;
    }       //确保不输出-0.0
    printf("(%.1f,%.1f)",ret.x,ret.y);
    return 0;
}
```
