> [!abstract] 本题概览
> 在不超过 80 个字符的字符串 $S$ 中查找字符 $c$ 首次出现的位置，若找到则输出从该位置起始的整个后缀子串，否则输出 `Not found`。核心练习==字符数组整行读取、指针线性遍历与标准库函数 `strchr()` 的等价思维==。

---

## 题目描述

输入一个字符串 $S$，再输入一个字符 $c$，要求在字符串 $S$ 中查找字符 $c$。如果找不到则输出 `Not found`；若找到则输出字符串 $S$ 中从 $c$ 开始的所有字符。

### 输入格式

输入在第 1 行中给出一个不超过 80 个字符长度的、以回车结束的非空字符串；在第 2 行中给出一个字符。

### 输出格式

在一行中按照题目要求输出结果。

### 输入样例 1

```text
It is a black box
b
```

### 输出样例 1

```text
black box
```

### 输入样例 2

```text
It is a black box
B
```

### 输出样例 2

```text
Not found
```

---

## 解题思路与核心知识点

### 1. 实现逻辑拆解

1. 用 `getchar()` 逐字符读入第一行直至 `'\n'`，存入 `char S[81]` 并手动写入 `'\0'`。
2. 再调用一次 `c = getchar()` 读入第二行的目标字符（因上一行的 `'\n'` 已被 `while` 条件消费，无需额外清理换行）。
3. 指针 `p` 从 `S` 开始顺序扫描，一旦 `*p == c`：
   - 置 `flag = 1`；
   - 从 `p` 开始向后逐字符输出剩余后缀；
   - 立即 `break`，确保只按**首次出现**的位置输出。
4. 若循环结束 `flag == 0`，输出 `Not found`。

### 2. 原始学习注释与易错点

| 源码行号 | 对应代码 | 原注释与核心解释 |
| :---: | --- | --- |
| 23 | 独立注释 | `char *S没有初始化` —— 同 `10-0`，C 语言中必须分配实际数组空间 `char S[81]`（80 字符 + 1 字节 `'\0'`），切勿向未初始化的野指针写入数据 |

### 3. 复杂度分析与进阶优化

- **当前实现时间复杂度**：$O(n^2)$（原因见下方警告）；优化循环条件后可轻松降至 ==$O(n)$==。
- **空间复杂度**：$O(n)$。

> [!warning] 循环条件中反复调用 `strlen(S)` 的隐性开销
> 源码第 31 行 `for (p = S; p < S + strlen(S); p++)` 在每次迭代都会重新遍历字符串计算 `strlen(S)`，导致本应 $O(n)$ 的查找退化为 $O(n^2)$。
>
> **两种更地道的 C 写法**：
> 1. 直接判断终止符：`for (p = S; *p != '\0'; p++)`；找到后直接 `printf("%s\n", p);` 即可输出从 `p` 开始的整个后缀，无需再写内层 `q` 循环！
> 2. 直接调用 `<string.h>` 标准库函数 `strchr`：
> ```c
> char *pos = strchr(S, c);
> if (pos != NULL) {
>     printf("%s\n", pos);
> } else {
>     printf("Not found\n");
> }
> ```

## 完整源码

```c
/*
输入一个字符串S，再输入一个字符c，要求在字符串S中查找字符c。
如果找不到则输出“Not found”；若找到则输出字符串S中从c开始的所有字符。
输入格式：
输入在第1行中给出一个不超过80个字符长度的、以回车结束的非空字符串；在第2行中给出一个字符。
输出格式：
在一行中按照题目要求输出结果。
输入样例1：
It is a black box
b
输出样例1：
black box
输入样例2：
It is a black box
B
输出样例2：
Not found
*/
#include <stdio.h>
#include <string.h>
int main (){
    char S[81],c,ch,*p=S;
    //char *S没有初始化
    int flag=0;
    while ((ch=getchar())!='\n'){
        *p=ch;
        p++;
    }
    *p='\0';
    c=getchar();
    for (p=S;p<S+strlen(S);p++){
        if (*p==c){
            char *q;
            flag =1;
            for (q=p;q<S+strlen(S);q++){
                printf("%c",*q);
            }
            break;
        }
    }
    if (flag==0){
        printf("Not found\n");
    }
    return 0;
}
```
