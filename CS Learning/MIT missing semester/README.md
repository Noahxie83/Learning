## 学习与补充

- 先阅读官网对应主题，再记录命令的用途、输入输出和容易混淆的概念。
- 笔记中的命令是学习材料，不应不经理解就批量执行；尤其注意文件删除、重定向覆盖和环境配置操作。
- Windows PowerShell 与 Bash 的语法不同，执行前确认所在环境。是否安装 WSL 或其他工具按学习需要另行决定。
- 后续新增笔记时更新此表；目前不把尚未归档的课程主题标记为已完成。
