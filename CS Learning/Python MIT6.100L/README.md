# Python MIT6.100L

MIT 6.100L Python 课程资料、课堂代码、练习题和实验记录。

## 内容范围

本目录按课程讲次整理 Python 学习内容，覆盖：

- Python 基础语法、变量、条件和循环。
- 字符串、列表、元组、字典和集合。
- 函数、作用域、递归和高阶函数。
- 面向对象编程。
- 测试、调试和程序设计。
- 算法复杂度与复杂度分析。
- NumPy、Matplotlib 和基础数据处理。
- 课程 Problem Set、Recitation 和实验代码。

## 目录特点

课程目录通常同时包含：

- 课堂讲义或笔记。
- 课堂演示代码。
- Recitation 练习。
- Problem Set 题目与代码。
- 测试资源和运行所需的数据文件。

运行课程代码前，建议先确认当前工作目录和资源文件路径；部分练习依赖同目录下的输入文件或图片资源。
