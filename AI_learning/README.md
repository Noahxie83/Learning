# AI_learning

人工智能入门学习资料与课程笔记。

## 课程概览

本目录主要整理 **AI for Everyone** 课程内容，包括课程 PDF、Markdown 测验记录、图片和学习笔记。

| 目录 | 内容 |
| --- | --- |
| [AI for everyone](./AI%20for%20everyone/) | AI for Everyone 课程资料 |
| [Week 1](./AI%20for%20everyone/Week%201/) | 第 1 周课程资料、测验和图片 |
| [Week 2](./AI%20for%20everyone/Week%202/) | 第 2 周课程资料和测验 |
| [Week 3](./AI%20for%20everyone/Week%203/) | 第 3 周课程资料、测验和图片 |
| [Week 4](./AI%20for%20everyone/Week%204/) | 第 4 周课程资料和测验 |

## 内容形式

- PDF：课程原始资料。
- Markdown：课程测验、答案记录和个人笔记。
- 图片：题目或课程内容中的配图。

## 推荐学习流程

1. 先阅读对应周次的课程 PDF。
2. 在 Obsidian 中打开 Markdown 测验和笔记。
3. 将不理解的概念、例子和问题补充到对应文件中。
4. 学完一个模块后，在笔记中记录总结和待复习内容。

## 使用方式

本目录可以直接作为 Obsidian Vault 打开：

```text
D:\Learning\AI_learning
```
