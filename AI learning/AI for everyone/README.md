# AI for Everyone

DeepLearning.AI 的 AI for Everyone 课程学习归档，课程入口：[AI for Everyone](https://www.deeplearning.ai/courses/ai-for-everyone)。

这门课是 AI Learning 主线的入门阶段，关注 AI 的基本概念、项目与组织中的应用，以及社会影响；后续机器学习、强化学习在上级模块中另行规划。
